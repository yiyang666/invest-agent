# Personal AI Investment OS

这是一个由AI Agent操作、以确定性代码为核心的个人场外基金投研与辅助决策系统。

它的出发点很朴素：人容易追涨杀跌、忘记当初为什么买、看到一段漂亮曲线就临时改策略。系统把那些需要稳定复用的步骤——取数、校验、计算、回测、风控、报告、归因和交易确认——固化为代码、CLI与项目级Skill，让Agent负责调度和解释，而不是在每次聊天里重新“凭感觉算一遍”。

> 本项目仅用于个人研究和辅助决策，不构成投资建议，也不承诺收益。

## 你可以怎样使用它

用户不需要记住所有命令，可以直接在项目会话中告诉Agent：

- “刷新基金数据，检查今天的数据是否完整。”
- “查看我的账户和持仓风险，先不要交易。”
- “比较这两只基金的收益、回撤、相关性和交易成本。”
- “把这个投资想法变成可回测的策略，不要看完结果再偷偷改参数。”
- “用相同现金流与631比较，并解释收益到底来自哪里。”
- “检查这只基金当前是否限购、申购费和赎回费是多少。”
- “生成本月研究报告和调仓草案。”
- “准备申购”，随后逐笔核对并明确确认。

Agent会先读取项目政策和能力目录，再调用已有的确定性接口。数据不够时补数据，规则过时时刷新规则，证据不足时明确阻断；不会为了给出一个顺耳答案而填造数字。

## 系统如何工作

```text
公开基金数据 + 爱基金只读账户 + 受控外部发现
                         ↓
              归档 / 脱敏 / 质量门禁
                         ↓
                   本地数据仓
                         ↓
          指标 → 策略 → 回测 → 独立风控
                         ↓
             决策报告与人工判断
                         ↓
          逐笔精确批准 → 受控申购 → 对账
                         ↓
              现金流 / 袖套 / 策略归因
```

系统中有三类能力：

- **CLI与Python模块**：执行确定性计算、校验和状态机；
- **项目级Skill**：告诉Agent在某类问题上应优先使用哪个接口，并约束正确做法；
- **MCP**：提供受控的外部数据发现，必须经过本地门禁后才能进入研究。

完整接口、Skill和MCP清单见[系统能力目录](docs/capabilities.md)。

## 当前系统已经具备

- 爱基金持仓、钱包、订单和交易规则的受审查只读访问；
- AKShare兼容的东财/同花顺采集器及基金公司公开净值源；
- 原始批次不可变归档、质量门禁和本地SQLite校验仓；
- 收益、波动、回撤、修复、相关性、集中度和市场状态；
- 场外基金申购费、T+确认、在途现金、份额、分红、限额和跨月队列回测；
- 631基准、策略注册表、滚动窗口、敏感性、压力和同现金流比较；
- 月度决策包、证据报告、解释验收和可回放Manifest；
- 15分钟一次性批准、额度门禁、未知状态恢复与订单对账；
- 现金流、组合、袖套和策略四层归因，以及策略生命周期人工评审。

Phase 0–8的工程地基已经闭合。当前重点不是继续堆框架，而是用真实数据运行系统、研究新策略并逐月积累前瞻证据。

## 当前个人政策锚点

项目当前权威比较基准是 `dca_baseline@1.5.0`，长期锚点为631：

- 60%长期资产；
- 30%防御资产；
- 10%科技卫星；
- 每月稳定投入3,000元，另有0–2,000元机动预算；
- 月度总投入硬上限5,000元；
- 不加杠杆，组合压力线约20%。

631是长期锚点和比较尺，不要求所有候选策略机械地按631执行。候选可以改变新增资金分配，但必须用相同现金流进行公平比较，并接受独立风控否决。

## Agent适合做什么

Agent适合：

- 编排已有数据、策略、回测、风控和归因能力；
- 把模糊想法冻结为版本化规则；
- 发现数据或产品规则缺口并选择正确的数据路径；
- 解释证据、反证和风险，而不是只展示最好看的结果；
- 维护可复现产物和跨会话上下文。

Agent不应：

- 根据新闻临场猜涨跌；
- 在提示词里手算并覆盖确定性结果；
- 把回测胜出说成未来收益保证；
- 自动替换基金、账户或交易方式；
- 未经逐笔确认提交真实订单；
- 用MCP、网页或模型输出绕过本地数据门禁。

## 交易安全边界

系统当前处于`controlled_live`：

- 只开放逐笔受控申购；
- 每笔必须展示基金、金额、账户、费用、协议及预期结果；
- 用户确认只对当前精确摘要有效，15分钟后或字段变化即失效；
- 网络超时、5xx或状态未知时不自动重试，必须先查订单并对账；
- 赎回、撤单和无人值守交易仍关闭；
- 策略、回测、报告、归因和MCP均不能直接生成或提交真实订单。

## 新会话如何快速接管

仓库根目录的[AGENTS.md](AGENTS.md)要求新Agent依次阅读README、架构、路线图、能力目录、投资政策及相关ADR。正常情况下用户无需重新讲完整历史。

如果想主动检查，可以告诉Agent：

> 先读取AGENTS.md和docs/capabilities.md，确认本次任务应复用哪些CLI、Skill和MCP，说明数据截止日与能力缺口后再开始。

## 本地环境与数据

- 当前项目环境：Miniconda / Python 3.12 / `.conda-env`；
- 爱基金SDK：项目隔离安装的`aijijin-sdk 0.2.0`；
- 本地数据、持仓、报告、数据库、日志和原始MCP响应统一位于`data/`，全部被Git忽略；
- 爱基金凭证位于用户目录，不进入项目；
- 股叉叉MCP只在`.codex/config.toml`保存环境变量名，不保存Bearer token。

新机器可以先创建隔离环境并安装已审查的爱基金本地wheel：

```bash
conda env create --prefix ./.conda-env --file environment.yml
.conda-env/bin/python -m pip install --no-deps \
  .agents/skills/thsfund/vendor/aijijin_sdk-0.2.0-py3-none-any.whl
```

认证和真实账户操作必须另行遵循[爱基金安全审查](docs/integrations/thsfund-review.md)，不能从Git恢复凭证。

提交与隐私边界见[Git提交与隐私政策](docs/repository-policy.md)。
