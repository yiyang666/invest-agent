# 分层风险预算与估值水位策略：赎回扩展草案 v0.3.0

状态：`draft_preperformance / research_only / live_redemption_disabled`

本草案不修改或替代已冻结的 v0.2.0。它在任何买入版绩效结果出现前，先记录赎回扩展的最小研究假设，防止根据回测结果临时发明卖出规则。正式运行前仍需完成产品规则发现、确定性实现、测试并另行冻结 v0.3.0 机器规格。

## 1. 为什么不直接做完整季度买卖

当前政策记录的基金资产约6,000元，而每月稳定新增3,000元、最高5,000元。现阶段新增资金相对存量很大，大多数普通偏离可以用买入补缺口修复；广泛赎回的边际价值可能较低，却会立即引入费率、持有批次、异步到账和来回交易。

因此先检验最有独立经济含义的一条卖出机制：当高波动卫星主题持续失去趋势确认时，是否通过分段退出改善组合尾部风险。核心季度卖出、估值驱动的总账户减仓和卖出防御资产暂不进入 v0.3.0。

## 2. 高层含义保持诚实

v0.2.0 与本草案中的 `R = 70% × C` 仍是“新增风险预算软目标”，不是可以强制执行的总账户硬上限。它可以停止把新钱投入风险资产，但不能仅凭估值或60日波动卖出核心仓。

若未来要把它升级为真正的总账户风险上限，必须另建版本，明确卖出顺序、容忍带、确认期和最大换手，并与本草案做独立增量比较。

## 3. v0.3.0唯一普通赎回信号

每月1日使用上月末前已经可见的数据。某个卫星主题同时满足以下条件时，才产生普通赎回请求：

1. 连续两个正式月度决策均为红灯；
2. 当前持有金额高于当月动态执行目标；
3. 超出动态目标的金额大于组合净值的1个百分点；
4. 存在满足产品规则且持有至少90个自然日的可赎回批次；
5. 数据质量、产品规则和组合风险门禁均合格。

黄灯只降低未来新增目标，不卖出。单月红灯只停止新增并开始确认，不卖出。

普通赎回请求金额为：

`50% × max(当前金额 - 动态执行目标金额, 0)`

主版本的1个百分点无交易带预注册敏感性为0.5、1.0和2.0个百分点。不得根据主历史结果选择最漂亮的参数；主版本固定1.0个百分点。

## 4. 订单与频率约束

- 每月最多形成一个合并赎回计划；同月其余主题按红灯持续月数、超配比例、基金代码依次排队；
- 一个合并买入计划和一个合并赎回计划合计占用每月最多两次主动调整额度；
- 月度计划拆成QDII开放日或到账事件，不重复计为新的主动决策；
- 单基金25%、主题30%或卫星20%上限突破时只产生独立风险复核和“减至合规范围”的计算方案，不因本草案自动提交；
- 产品清盘、合同漂移、暂停赎回或巨额赎回属于产品事件，不冒充红绿灯信号。

## 5. 持有批次和赎回费用

每次申购确认必须形成独立持有批次，至少保存确认日期、份额、成本、份额类别和规则版本。卖出时：

- 按基金合同、登记机构或渠道已经核验的批次消耗顺序选择份额；
- 每批独立计算持有日和有效日期赎回费率；
- 未满90日的批次不参与普通信号赎回；
- 批次顺序、费率、最低赎回份额、份额精度或开放日未知时，该基金的卖出信号为 `ineligible`，禁止用行业惯例补空；
- 净值已扣除的管理费、托管费和销售服务费不得重复扣除。

## 6. 赎回现金状态机

```text
可用份额
  → 提交赎回后冻结为在途赎回份额
  → 按合格开放日净值确认并扣除批次费用
  → 已确认、未到账赎回款
  → 到账后的内部现金
  → 下一个固定月度决策才可参与目标缺口分配
```

确定性规则：

1. 提交赎回时不增加现金；
2. 到账前的赎回款不可申购，但继续作为组合应收资产参与净值守恒；
3. 到账当月不临时寻找新主题，不进行同周期回转；
4. 下个月将其作为既有现金纳入组合，但不计为外部投入、不占用或扩大3,000–5,000元预算；
5. 先按当月最新动态执行目标计算缺口；没有合格缺口就留现金；
6. 卖出主题若仍为红灯或黄灯，不得因静态20%卫星上限被重新买回。

## 7. 比较矩阵

| 路径 | 卖出 | 作用 |
|---|---|---|
| 固定3,000元631 v1.5 | 否 | 权威固定现金流基准 |
| matched-cashflow 631 v1.5 | 否 | 排除候选额外投入本金 |
| 候选 v0.2.0 | 否 | 分层买入逻辑与D4消融基线 |
| 候选 v0.3.0 | 仅连续红灯卫星 | 测量赎回的增量贡献 |
| 简单631带宽再平衡对照（后续） | 相同引擎与频率 | 检查复杂策略是否胜过简单卖出纪律 |

主赎回裁决看 v0.3.0 相对 v0.2.0 的费用后变化；对631的比较同时报告，但不能把不同卖出权限造成的差异伪装为单一因子收益。

## 8. 晋级条件

v0.3.0只有同时满足以下条件，才值得继续研究完整季度买卖：

- 没有突破15%历史回撤控制线或20%压力否决线；
- 相对v0.2.0的最大回撤或最差滚动窗口有稳定改善；
- 改善不是只来自长期持有大量现金；
- 赎回费、现金到账延迟和换手后仍成立；
- 0.5/1.0/2.0个百分点无交易带的多数结果同方向；
- 不依赖某一个主题、某一段市场或富时代理数据；
- 确定性复跑、现金守恒和时点测试全部通过。

若赎回只降低收益、没有明显改善尾部风险，则停止在 v0.3.0，不建设完整卖出轮动。复杂度本身不构成晋级理由。

## 9. 发现阶段仍需补齐的事实

对每条实际基金路线分别核验：赎回费率阶梯、生效日期、持有日口径、批次消耗顺序、最低赎回份额、份额精度、截止时间、开放日、确认日、到账日、QDII特殊日历、暂停/巨额赎回处理和渠道差异。

这些是外部事实，不需要用户猜测。无法从官方合同、招募说明书、公告和独立来源唯一确认时，再集中形成发现分叉。
