# 指数估值月频面板数据契约 v0.2.0

状态：`preimplementation / research_only`

本契约服务于 `hierarchical_risk_budget_valuation@0.2.0` 的D4三版本和核心袖套估值倾斜。它定义远程发现、不可变归档、标准化、质量门禁、月频化和缺失处理；不授权任何MCP在策略、指标、回测、报告或交易运行时被实时调用。

## 1. 唯一允许的数据流

```text
远程网页 / API / MCP / 官方文件
  → 去敏原始响应不可变归档
  → schema与来源质量门禁
  → 标准化指数估值观察
  → 独立第二来源交叉检查
  → 发布到本地校验仓的版本化研究批次
  → 月频面板快照
  → D4和核心估值原语
```

运行中的策略只能读取已经发布、带批次ID和哈希的本地快照。远程失败时不得现场抓取、自动重试、切换来源或回落到模拟数据。

## 3. 原始批次必需字段

每次远程采集必须先保存原始响应，再解析。批次元数据至少包含：

- `batch_id`；
- `provider_id`与真实上游域名；
- 工具、端点或文件URL；
- 完整但去敏的请求参数；
- `fetched_at`与研究 `as_of`，均带时区；
- MIME类型、压缩方式和适配器版本；
- 原始内容SHA-256；
- 远程服务版本、协议版本或schema哈希（可获得时）；
- 成功、应用层错误、超时或拒绝状态；
- 明确声明未保存Authorization头、Bearer token和账号私人数据。

任何既有批次不得覆盖。修订只能创建新批次并保留旧版本。

## 4. 标准化观察字段

| 字段 | 规则 |
|---|---|
| `series_id` | 使用第2节冻结身份，不直接使用网页显示名 |
| `index_code` | 冻结内部代码，如 `CSI300`、`SP500`、`NDX` |
| `metric` | 本版本仅接受 `pe_ttm` |
| `value` | 正数Decimal；禁止浮点字符串静默截断 |
| `observation_date` | 上游数据所属市场日期 |
| `published_at` | 上游可信发布时间；未知保持空 |
| `first_seen_at` | 本系统首次真实采集时间 |
| `as_of` | 本批次研究截止时间 |
| `frequency` | `daily`、`weekly`或`monthly`，不得猜测 |
| `calculation_method` | 如 `aggregate_market_cap_over_ttm_profit` |
| `market_scope` | `exact_index`或`country_total_market_proxy` |
| `proxy_for` | 仅代理记录填写目标指数 |
| `source_methodology_version` | 可获得时保存，否则为空并告警 |
| `visibility_grade` | `strict_point_in_time`或`historical_visibility_assumed` |
| `batch_id` | 追溯原始响应 |
| `raw_sha256` | 原始内容哈希 |
| `quality_status` | `pass`、`partial`或`rejected` |

指数代码相同但计算方法、市场范围或上游来源不同的观察不得静默合并为一条序列。

## 5. 月频标准化

D4只使用月频面板，以消除日频、周频和月频输入对历史分位的机械影响：

1. 按北京时间自然月分组；
2. 每个 `series_id` 选择月末23:59:59前已经可见的最后一个合格观察；
3. 不前向填充缺失月份；
4. 每个指数独立保留最多120个月，至少需要60个月；
5. 连续缺失超过2个月或120个月窗口覆盖率低于90%时，该指数当期不合格；
6. 当前月份只有在月度决策截止前已经完整结束时才能进入窗口；
7. mixed-frequency来源先各自月频化，再进行跨源比较，禁止先拼接原始频率。

经验分位采用：

`percentile = count(window_value <= current_value) / valid_window_count`

窗口包含当前月末值。相同输入批次、截止日和参数必须产生完全相同的面板哈希与分位结果。

## 6. 时点等级

- 本系统从现在开始真实采集并保存 `first_seen_at` 的当前值，可以在该时间之后取得 `strict_point_in_time`；
- 只带历史日期、没有可信发布时间的回填记录标记 `historical_visibility_assumed`；
- 不得把 `observation_date`加工成虚假的 `published_at`；
- 历史回填只允许研究筛选，不能声称严格样本外；
- 每个回测月必须保存所用面板快照ID、内容哈希和最大可见时间。

## 7. 质量门禁

以下任一情况拒绝观察或当月输入：

- 缺provider、真实域名、批次、时区、日期、数值或哈希；
- PE非正、NaN、无限或单位不明；
- 观察日期晚于批次 `as_of`；
- 同来源同指数同日期重复且数值冲突；
- 精确指数记录实际是国家整体市场代理；
- schema漂移、分页不完整或应用层返回 `isError`；
- 原始响应无法重放出相同标准化结果。

长缺口、方法版本未知、异常跳变或代理数据可以发布为 `partial`，但必须携带警告，不能被报告层隐藏。

## 8. 跨源一致性

主源与交叉源不做平均，也不自动选择“更顺眼”的值。预注册门槛：

- 同期PE相对差异超过5%：警告并要求口径说明；
- 同期PE相对差异超过10%：该月输入不合格；
- 各自历史百分位差异超过10个百分点：警告；
- 各自历史百分位差异超过20个百分点：该月输入不合格；
- 已知计算方法或市场范围不同：只做方向性诊断，不应用数值容差裁决。

任何冲突都保留两条来源和证据，不覆盖、不平均、不由LLM裁决。

## 9. D4缺失行为

- `d4_0_volatility_only`不依赖估值数据，固定 `V=1.0`；
- `d4_2_dual_consensus`要求沪深300和纳指100同时合格，否则 `V=0.9 / evidence_insufficient`；
- `d4_5_core_weighted`要求五个输入同时合格；使用英国整体市场代理时必须标记 `proxy_research_only`；任一输入缺失则 `V=0.9 / evidence_insufficient`；
- 不重新归一剩余指数权重，不用相邻国家或另一个美国指数填补缺失；
- 缺失行为只控制估值系数，不能绕过独立风险否决。

## 10. 股叉叉晋级条件

从 `discovery_only` 晋级为可发布的研究采集源前必须完成：

1. raw-first确定性采集适配器，禁止保存凭证；
2. `get_index_valuation`正式输入/输出schema、分页、最大响应和应用层错误测试；
3. 各目标指数历史起止日、频率、方法和代理标签实测；
4. 原始响应重放、schema漂移、超时、无效token和频率限制测试；
5. 数据保存、派生计算和报告引用许可依据；
6. 与蛋卷、指数公司或其他独立来源的小样本一致性报告；
7. 本地校验仓新增指数估值隔离表，不写入基金NAV表；
8. 明确证明策略、回测、报告和执行模块不能直接调用MCP；
9. 新增ADR或等价架构审查后，才允许 `publish_to_validated_store=true`。

在以上条件完成前，股叉叉仍可用于人工研究发现和来源核验，但不能缩短本契约的数据门禁。
