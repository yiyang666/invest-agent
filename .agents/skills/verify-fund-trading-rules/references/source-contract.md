# 数据源与字段契约

## 来源优先级

1. 爱基金 `aijijin` CLI 当轮只读预检：当前渠道规则的唯一远端事实源。
2. 项目本地已校验、版本化产品规则：用于复现和离线研究；不得把它冒充为当前规则。

不得为了补字段、解决冲突或核验历史而搜索合同、招募说明书、基金公司网页或其他公开网页。CLI 字段缺失、冲突或无法证明历史时，保留为未知；依赖该字段的正式交易或回测失败关闭。

## 申购规则

按 `thsfund` 申购参考执行：

```bash
aijijin fund subscribe-init --fund-code "$fundCode"
aijijin fund fee-rule --fund-code "$fundCode"
```

仅提取并展示：

- 基金代码、名称、渠道可购/暂停/限购状态；
- 起购金额、追加金额、单笔最大购买及当日渠道限制；
- 产品风险等级；
- 原始申购费率阶梯及银行卡/钱包折扣；
- 管理费、托管费、销售服务费；
- 封闭或持有期提示、预计确认信息。

不要把银行卡支付限额误写成基金日限购。基金限购、单笔申购上限、银行卡单笔限额和银行卡单日限额必须分栏展示。A/C份额是否共享限额只有渠道明确返回或用户实测确认时才能合并。

## 赎回规则

先按份额类别查询持仓并定位目标基金的精确交易账户，再渲染赎回预览：

```bash
aijijin holding list --share-category 01
aijijin fund redeem-render \
  --fund-code "$fundCode" \
  --transaction-account-id "$transactionAccountId"
```

目标基金不在 `01` 时，按 `thsfund` 参考查询其他份额类别。多账户持有时先让用户选择银行名称和尾号对应的账户；不得猜测。

仅提取并展示：

- 当前净值及净值日期；
- 可用份额、最低赎回份额和最低剩余份额；
- 每笔持有份额与持有天数；
- 阶梯赎回费率；
- 是否支持赎回至钱包；
- 钱包/银行卡预计到账时间。

赎回费按当前持有批次和先进先出规则估算。费率字段是小数比例：`0.0150` 表示 `1.50%`，不是 `0.015%`。估算式为 `份额 × 当前净值 × 费率`，分批求和后按人民币分舍入。

## 失败与降级

- CLI 明确返回业务失败：展示可读原因，不替换基金、账户或渠道重试。
- CLI 字段缺失：标为未知；依赖该字段的当前交易或正式回测失败关闭。
- CLI 网络或服务异常：不连续重试，不以网页、合同或旧记录冒充渠道规则。
- 查询历史规则：只使用本地已有且带生效日的版本化规则；缺失时不可用。当前 CLI 结果只能作为当轮渠道事实或反事实执行假设。

## 隐私

禁止保存或展示原始响应中的完整 `bankAccount`、`transactionAccountId`、`custId`、token、设备标识或凭证。允许保存基金代码、脱敏账户别名、规则字段、来源命令、核验时间和响应内容哈希；不得保存能还原账户的映射。
