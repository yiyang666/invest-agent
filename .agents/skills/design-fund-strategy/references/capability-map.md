# 当前策略研究能力图

## 可以直接复用的确定性底座

| 能力 | 入口 | 状态 |
|---|---|---|
| 校验后的本地净值与批次证据 | `invest_agent.data` | 可复用；回填历史仍可能只有假设可见性 |
| 单基金收益、波动、回撤、相关性 | `invest_agent.metrics` | 可复用 |
| 当前权重组合风险代理 | `invest_agent.metrics.portfolio` | 可复用；不等于完整持仓交易回放 |
| 申购、确认、费用、份额与现金状态 | `backtest.subscription_engine` | 可复用；申购路径完整 |
| 单位净值估值与分红 | `backtest.valuation_engine` | 可复用 |
| TWR、年化收益、XIRR、波动、回撤、现金拖累 | `backtest.local_research.calculate_path_metrics` | 可复用 |
| 目标缺口定投、多路线、共享限额、跨月队列 | `backtest.local_research` | 可复用 |
| 滚动窗口、参数敏感性 | `backtest.rolling`、`backtest.sensitivity` | 可复用 |
| 非概率压力情景 | `risk.stress` | 可复用 |
| 策略身份、版本、规格/证据哈希 | `decision.registry` | 可复用；保持 research_only |
| 现金流/TWR、同现金流比较、袖套Brinson、顺序消融 | `invest_agent.attribution` | 可复用；归因不生成订单，生命周期只进入人工评审 |

## 已有信号原语

- 日历定投与631目标缺口；
- 绝对趋势、慢均线和相对强弱；
- 组合回撤分档预算；
- 袖套回撤与修复信号；
- 组合压力、单基金和主题上限。

这些原语可减少新代码，但当前没有任意组合规则 DSL。新组合仍要增加一个薄的确定性编排函数、场景配置和测试。

## 快速路径与探索路径

满足以下全部条件才走快速路径：

- 基金已有本地校验历史和产品规则；
- 袖套已有经济暴露定义、压力映射和上限；
- 信号原语已有确定性实现；
- 所需数据已进入本地仓；
- 不改变631长期锚点。

任一条件不满足就走探索路径。探索可以自主调用本地工具、受控采集和公开网页，不应因此反复询问用户。

## 新基金证据阶梯

| 证据等级 | 可做什么 | 不能声称什么 |
|---|---|---|
| `fund_history` | 基金自身历史回放 | 严格样本外，除非时点条件满足 |
| `short_fund_history` | 短窗比较、前瞻观察 | 长周期稳健性 |
| `index_proxy` | 经济暴露和信号背景 | 基金真实费率、跟踪误差与成交路径 |
| `older_fund_proxy` | 相似产品历史诊断 | 新基金自身历史表现 |
| `forward_only` | 压力、安全和未来观察 | 历史收益优势 |

代理结果必须单独展示基差风险；不得把代理和基金真实历史拼成一条无标记净值线。

## 新袖套契约

袖套是经济暴露，不是基金代码。新增袖套至少冻结：

- 资产类别、地区、指数/风格和币种；
- 汇率对冲状态；
- `tactical_overlay` 或 `policy_candidate` 角色；
- 策略与组合权重上限；
- 与现有袖套的重叠/相关性说明；
- 压力情景映射；
- 一条或多条基金实现路线。

`policy_candidate` 需要单独的政策与 ADR 候选；不能由自定义策略静默改变631锚点。

## 当前显式硬编码边界

- `backtest.local_research` 只识别 `target_gap`、`new_money_trend_rs`、`drawdown_budget_add`、`sleeve_drawdown_recovery` 等已有模式。
- `decision.monthly` 逐个构造四个已有策略信号。
- `decision.reporting` 固定了四个策略标签和载荷解释。
- `approval.drafts` 要求唯一 `dca_baseline` 目标权威。
- 当前研究引擎没有通用赎回/全组合轮动路径；新策略默认只管理新增资金。

因此，当前系统能可靠承载“新增资金、月频、稳定+灵活、买入为主”的多种组合策略，但不能仅靠一份配置自动运行任意新因子、卖出择时、高频或衍生品策略。

## 能力沉淀规则

- 单一策略特有的组合逻辑：保留在该策略模块。
- 被至少两个策略复用、数据契约稳定且可独立测试：提升为通用原语。
- 新资产类别、新数据源、新回测语义或安全边界：进入基础设施；重大影响新增 ADR。
- 新数据源或第三方依赖：先静态审查并取得用户批准，固定版本与校验值，禁止自动更新。

## 每个新策略必须补齐

1. 版本化提案和正式策略规格；
2. 必要时完成发现报告；
3. 新原语或组合函数的单元测试；
4. 候选与631的相同现金流场景；
5. 路由、费用、限额和确认语义；
6. 滚动、敏感性、压力与确定性复跑；
7. 研究证据报告；
8. 用 `invest_agent.attribution` 生成同现金流相对结果；涉及多个规则时先冻结顺序消融阶段和claim scope；
9. 如需月度展示，再单独接入 decision/reporting；
10. 如需改变长期锚点，另做政策和 ADR 变更。
