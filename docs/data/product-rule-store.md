# 场外基金产品规则库

规则库使用 `schemas/fund_product_rules.schema.json` 约束版本化快照，并与净值仓分开：净值回答“值是多少”，规则回答“何时受理、按哪天净值确认、多久确认或到账、收多少费用、是否限购”。

## 权威等级

- `reference_only`：非爱基金渠道的旧记录或展示信息，只用于定位和初筛；
- `official_verified`：爱基金 CLI 当轮只读预检已返回的渠道字段，必须保存来源命令、核验时间与脱敏证据；它只证明当前渠道规则，不证明历史规则。

未知值保存为 `null` 并列入 `unknown_fields`。禁止用行业惯例补空，因为 QDII、节假日、代销规则和临时限购都可能改变实际结果。

## 版本规则

1. 来源或规则变化时生成新 `snapshot_id`，旧快照只读保留；
2. 每项规则保存权威等级、来源、生效日期和备注；
3. 法定费率、渠道折扣和份额类别必须分开；
4. 暂停申购、单日限额等按核验时点追加，不覆盖旧快照；
5. 回测必须绑定规则快照；当前渠道快照用于历史回测时一律标记为反事实执行假设，`provisional` 规则只允许研究性运行。

本机规则快照位于被 Git 忽略的 `data/private/rules/`。当前仍有部分渠道费率、动态限购、确认/到账周期及 QDII 日历处于 `provisional`，相关回测必须明确标记假设。
