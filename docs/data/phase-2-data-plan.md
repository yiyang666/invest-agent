# 数据层方案

目标是把不稳定的远端采集转换成可校验、可重放、可降级的本地数据资产，而不是依赖某个“永不失效”的免费接口。

## 架构

```text
远端与官方来源 → 原始不可变批次 → 标准化与质量门禁 → 本地校验仓 → 指标/回测
                                        ↑
爱基金只读预检 → 脱敏版本化产品规则库 ┘
```

本地校验仓是指标与回测唯一允许读取的数据源。AKShare 仅用于低频采集，不在分析或回测时实时调用；远端失败时读取最后一个已验证批次并显示陈旧状态。

## 数据源分工

| 数据 | 默认来源 | 用途与限制 |
|---|---|---|
| 实时账户、持仓、订单 | 爱基金 `thsfund` | 组合真相与对账；默认只读 |
| 基金基本信息 | AKShare `fund_info_ths` + `fund_name_em` | 同花顺接口只返回基本信息键值，不是历史净值接口 |
| 历史净值 | AKShare 东财接口 | 回填主通道；保存底层站点、接口版本和抓取时点 |
| 日度交叉检查 | AKShare 同花顺接口 | 形成第二站点观测，不假定完整历史覆盖 |
| 分红、申购状态、季度持仓 | AKShare 东财接口 + 官方披露 | 持仓按报告期和公告日存储，只能形成滞后低频因子 |
| 费率、开放日、确认/到账和限额 | 爱基金 `aijijin` CLI 当轮只读预检（`subscribe-init`、`fee-rule`、`redeem-render`） | 当前渠道事实；脱敏后按核验时点版本化，不证明历史规则 |
| 官方/授权导出 | `LocalCsvNavProvider` | 上游中断时的人工可复现导入通道 |
| 鹏华官方历史净值 | 鹏华官网公开接口 | 鹏华产品的官方数值核验；原始分页先归档 |

同一 Python 包不等于同一来源。`akshare_ths` 和 `akshare_eastmoney` 必须分别记录真实底层域名，以识别站点故障与冲突。

## 本地存储

- `data/raw/`：不可变公共数据批次、请求参数和内容哈希，不进 Git；
- `data/private/`：SQLite 校验仓、脱敏账户历史和运行状态，不进 Git；
- 标准化记录可追溯到原始批次，修订采用追加版本，不覆盖旧记录。

SQLite 足以覆盖个人基金池并便于备份、迁移和离线重放；只有实际规模或并发需求出现后再评估独立数据库。

## 时点等级

免费历史数据的主要缺口往往不是净值数值，而是“当时何时可见”：

- `strict_point_in_time`：上游提供可信 `ann_date`，或该记录由本系统实时采集并保存 `first_seen_at`。可进入严格时点回测。
- `historical_visibility_assumed`：仅有净值日期，采用保守的下一可用日假设，只能用于研究筛选。

净值记录至少包含净值日期、单位/累计净值、采集时点、首次可见时点、可见性等级、批次和内容哈希。未知公告时间保持为空。

## 基金历史窗口

基金代码可能在转型或新合同替代后延续使用。为保持日常任务轻量，当前不做合同网页/PDF核验，也不生成合同核验待办。新基金首次仅回补固定最近三年；之后按重叠窗口增量更新。该窗口是数据采集约束，不构成基金经济身份连续性的证明；涉及长历史研究时必须披露身份连续性未经核验，不能将窗口外数据作为结论依据。

## 工具边界

- `fund-data-collect`：采集、原始归档、质量检查和发布；
- `fund-metric-calc`：只读本地校验仓，计算确定性指标；
- 内部事件引擎：当前批量回测的权威实现；
- xalpha：只可读取本地数据做指标参考，不启用其爬虫；
- cjquant：尚未安装，仅保留为未来隔离实验后端；通过场外基金回测契约后才可用于结果对照，禁止其执行模块；
- FinClaw：只借鉴设计，不整包安装或回落到示例数据。

## 质量门禁

1. 记录具有来源、底层站点、批次、抓取时点、可见性等级和哈希；
2. 重复、非正净值、日期倒序、异常跳变和长缺口均有检测；
3. 跨源冲突必须隔离，禁止静默选值；
4. 失败批次保留审计信息，禁止回落到模拟数据；
5. 同一批次重放必须得到相同输出和哈希；
6. 费率、截止时间、确认/到账、暂停/限额和 QDII 日历只从爱基金 CLI 的当轮只读结果脱敏后进入版本化规则库；缺失字段保持未知。

## 当前状态

主数据、历史净值、本地仓、原始归档、跨源核验、故障降级和确定性重放均已投入使用。160646 的鹏华官网与东财共同覆盖 1,137 个净值日，数值冲突为 0。

尚未完全权威化的部分是分红口径、渠道费率、动态限购、确认/到账周期及 QDII 日历。因此涉及这些字段的历史模拟仍需标记为研究假设；它们是后续数据完善项，不阻断只读账户评估和已有基准比较。
