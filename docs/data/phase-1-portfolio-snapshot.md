# 组合快照契约

爱基金只读结果先转换为统一、可核对且不含账户标识的 `PortfolioSnapshot`，再进入指标与决策层。快照只描述事实，不生成交易指令；结构由 `schemas/portfolio_snapshot.schema.json` 约束。

## 保留字段

- 数据时点、来源、批次和质量状态；
- 现金、基金市值、总资产；
- 基金代码、名称、份额、市值、权重和净值日期；
- 可解释的数据异常。

## 隐私边界

账户号、银行卡号、客户号、设备号、证件、手机号及任何 token、密钥或密码均不得持久化。原始爱基金响应只在内存处理；脱敏快照仅保存到被 Git 忽略的 `data/private/portfolio_snapshots/`，并限制为当前用户可读写。

“脱敏”不等于“公开”：持仓仍属于个人财务隐私，不提交 Git、不上传外部服务。

## 质量门禁

- `pass`：关键字段齐全且无异常；
- `partial`：可用，但存在明确的非阻断警告；
- `fail`：重复基金、负数金额、非法代码、缺少时区等关键错误。

金额统一使用十进制数。模型、序列化、敏感字段检查、爱基金只读采集及本地脱敏历史链路均已验证。
