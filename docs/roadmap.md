# 路线图

## 已完成：研究闭环（Phase 0–5）

- 投资政策、安全边界和架构已冻结；
- 爱基金只读账户、脱敏快照与本地私有历史可用；
- 基金主数据、净值、分红和来源质量进入本地数据仓；
- 收益、波动、回撤、相关性和基金状态指标可复现；
- 场外基金事件回测、631基准和三个研究策略已实现；
- 策略注册表、风险门禁、证据报告和月度流水线已收口。

研究工程状态为`closed`；无人值守生产执行仍为`blocked`，逐笔精确批准的受控申购为`active`。现阶段不再按阶段编号堆叠新框架，只根据真实使用暴露的问题迭代。

## 当前工作：真实数据下的辅助决策

1. 每个工作日晚间增量同步政策基金、当前可购路由和真实持仓，失败批次不发布；
2. 每次分析前刷新只读持仓、检查在途交易和数据新鲜度；
3. 运行持仓风险、目标偏离和费用/限额检查；
4. 输出分阶段调整草案，不把研究触发直接变成交易；
5. 记录实际使用中缺失的能力，避免提前建设低价值功能。

当前仍需长期积累严格时点和前瞻样本外数据。历史回填结果继续是 `research_only`。

QDII购买候选只含开放或限购产品；只有相互独立的限额才能跨路由合并，A/C共享限额按一个容量组计算。不支持交易的产品不进入购买候选，但已有持仓仍须持续监控。美国宽基由017641/019305共享日限10元的标准标普500路线，加上096001独立日限10元的标普500等权路线补足月度容量；519981以日限10元、申购费0.14%的第四优先级后备路线提供容错，但不承担标准标普500基准角色。七袖套631 v1.5已完成多路由回测、3,000–5,000元月供敏感性、压力测试、权威迁移和首个真实持仓诊断包，国内成长采用019861；后续持续积累前瞻样本外数据。011706不进入购买或日常同步池。

## 已完成：Phase 6 人工审批与模拟执行

Phase 6.1已完成：

- 不可变订单摘要和15分钟一次性批准契约；
- 金额、基金、账户、费用或预期结果变化后旧批准失效；
- 重复消费、过期批准和未知状态重试失败关闭；
- mock对账状态机不联网、不产生外部副作用。

Phase 6.2已完成：

- 只有风险合格、日期冻结、来源仍为零订单的计划才能生成mock草案；
- 基金、金额、日期、费用、路由规则、账户别名和来源证据共同绑定摘要；
- 当前月中诊断包因风险复核状态被拒绝，生成0笔草案；
- SQLite批准跨进程有效，并发消费最多一笔成功，库内不保存账户或基金明文。

Phase 6.3已完成：

- 批准消费和 `submitting` 状态在同一SQLite事务内完成；
- 提交前崩溃完整回滚，提交后崩溃在重启时转为 `unknown`；
- `unknown` 对账前禁止再次提交；
- 本地交互式演练必须输入完整订单摘要；
- 执行日志不保存基金、账户、支付信息或凭证明文。

## 已完成：Phase 7 受控实盘入口

Phase 7.0入口准备已完成：

- 项目环境中的 `aijijin-sdk 0.2.0` 已复核；
- 真实 `aijijin fund buy --dry-run` 命令结构已验证，无网络和订单；
- 受保护适配器会校验单笔上限、基金/金额/支付账户绑定和网关域名，并去除返回值中的账户明文；
- 自动化适配器仍拒绝直接提交，首笔真实交易通过受审查的CLI逐步流程执行。

Phase 7.1首笔试运行已收口：006932申购500元已由基金公司确认，确认份额与实时持仓一致，脱敏记录已落地。Phase 7.2已完成持久化逐笔批准、原子额度门禁、提交中状态、崩溃恢复和未知状态对账；网关不自动调用交易CLI。撤单不作为测试安全保障。

爱基金CLI的当轮只读交易预检是动态申赎规则的首选事实源。`redeem-render` 已验证可返回当前持有批次、阶梯赎回费、可用份额、最低保留份额及到账时间；系统只保存归一化脱敏事实，赎回提交权限仍关闭。

## 已完成：Phase 8 归因与策略生命周期

- 真实现金流拆分本金、投资损益、费用与现金拖累，组合收益使用Modified Dietz并几何链接；
- 候选与631只有在现金流和估值期间匹配时才报告相对结果；
- 袖套贡献拆为配置、选择和交互效应，现金保持显式；
- 策略贡献使用预先冻结的顺序消融，不把资产池变化包装成信号alpha；
- 生命周期以版本、证据哈希、至少12个月前瞻观察和独立风险否决为门禁，只进入人工评审。

Phase 8的工程能力已关闭，真实前瞻证据仍需按月积累。归因入口见`invest_agent.attribution`和`docs/attribution.md`。

## 下一步：运行已经闭合的系统

1. 每月保存真实快照、外部现金流、费用和估值期间；
2. 对新策略先冻结同现金流比较与消融顺序，再运行归因；
3. 用归因结果解释收益来源、风险代价和现金拖累，不凭单次胜负晋级；
4. 满足前瞻观察窗口后进入人工生命周期评审；
5. 赎回和撤单如需开放，另行安全审查并保持逐笔确认。

不在当前路线中的事项：自动化高频交易、杠杆、依据新闻预测短期市场、LLM绕过确定性计算直接下单。
