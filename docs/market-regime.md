# 全球市场状态评估

`GlobalMarketStateSnapshot`回答的是“截至某个时点，我们对全球金融市场处于什么状态掌握了多少”，不是“明天涨还是跌”。

## 七个观察轴

| 轴 | 主要问题 | 当前状态 |
|---|---|---|
| 趋势 | 中、美、港、欧、日权益价格处于怎样的中期趋势和回撤 | 中港美欧日基金净值代理已接 |
| 估值 | 主要市场估值处于自身历史哪个区间 | 中、美、港、欧、日均有代理；日本当前值可能陈旧 |
| 宏观增长 | 生产、就业和增长是在改善还是收缩 | 中国制造业与美国非农/失业率周期代理已接；欧洲和日本仍缺 |
| 流动性/利率 | 收益率曲线、美元和融资条件是否宽松 | 中美日国债、外汇已覆盖 |
| 风险压力 | 波动、回撤、金融条件与杠杆压力是否上升 | 两融、NFCI和中港美欧日基金代理平均回撤已接 |
| 市场宽度 | 上涨是否由多数资产参与，还是少数权重拉动 | 股叉叉全A聚合宽度已接；全球宽度仍缺 |
| 拥挤/资金流 | 行业交易是否拥挤，资金是否集中或撤离 | 31行业综合拥挤中位数已接；跨市场流待接 |

配置文件`config/global_market_regime_v1.json`先冻结完整能力分母。未接入的特征不会被删除或填0，而是进入`missing_capabilities`并降低覆盖率。

## 计算与置信度

每个特征只允许使用配置里冻结的本地序列和显式阈值。计算器支持最新值、两序列利差、历史分位、区间收益、均线偏离、单序列/多地区平均回撤和横截面中位数等通用变换；所有输入先按`observation_date/published_date/first_seen_at`执行截止门禁。

输出同时包含：

- 已观察证据的方向分数；
- 七轴覆盖率；
- 严格点时证据占比；
- 独立来源数量；
- 陈旧、历史不足、未接入和日期不对齐等缺口；
- 批次ID、内容哈希和配置哈希。

总体状态至少需要60%加权覆盖。正式决策资格要求更高：至少80%覆盖、全部严格点时、至少两个独立来源，且仍要经过独立风险层。当前v0.5即使覆盖超过80%，仍因严格点时不足而固定`research_only`；Schema进一步禁止预测、策略信号和订单输出。

## CLI

```bash
.conda-env/bin/python -m invest_agent.market_regime.cli \
  --as-of 2026-08-29 \
  --config config/global_market_regime_v1.json \
  --db data/private/invest_agent.sqlite3
```

该命令纯本地只读。需要补数据时先走`market-data-collect`；需要解释快照时走`market-context-research`。不要让解释模型现场换阈值或绕过缺失项。

## 当前v0.5边界

v0.5在v0.4基础上接入华夏恒生ETF联接A（000071）作为香港宽基趋势代理，并用已有的美国非农新增就业与失业率历史分位组成双指标就业周期代理。2026-08-30真实本地样例覆盖88.5%，状态由`supportive`校正为`balanced`，置信度66.625（medium），但`formal_decision_eligible=false`。香港趋势高于120观察均值1.13%，属于均衡；美国非农新增就业处于15.25%低分位、失业率处于29.73%低分位，呈现就业增量走弱但失业率仍低的冲突。纳入香港后，中港美欧日252观察平均回撤从-4.26%扩大为-5.43%，风险轴由偏支持降为均衡。

趋势和回撤代理不是官方指数：香港、美国、欧洲、日本代理均包含人民币汇率、基金费用与QDII净值滞后，DAX不能代表全部欧洲。股叉叉页面报告A股总数5554，但上涨、下跌和平盘合计5208；系统显式保留346只未分类证券，并用5208作为上涨占比分母。回填旧历史标记为`historical_visibility_assumed`，从系统上线后的首次观察才逐步形成严格时点历史。日本估值、欧洲/日本增长周期、全球宽度和跨市场资金流仍缺失。

数据源评审见`docs/integrations/market-regime-source-review.md`，架构决策见`docs/decisions/ADR-0030-global-market-state-assessment.md`。
