# 金十数据 MCP 精简集成审查

- 首次审查：2026-09-13
- 官方服务地址：https://mcp.jin10.com/mcp
- 认证：Bearer token；项目代码只读取`JIN10_MCP_TOKEN`
- 当前状态：交互能力与raw-first正式采集均已实测；精选报价和关键宏观发布已纳入现有工作日日频总控
- 用途：个人本地研究、跨资产即时状态和经济事件背景；不预测市场、不生成策略或订单

## 工具筛查

当前MCP暴露八个工具和一个`quote://codes`资源。项目按价值最小化接入：

| 工具 | 决策 | 用途 |
|---|---|---|
| `get_quote` | 正式采集允许 | 精选中港美英欧日指数、黄金、原油和三组外汇的当前价格与涨跌幅 |
| `list_calendar` | 正式采集允许 | 当前自然周经济日历；只发布明确映射的欧洲、日本关键宏观值与实际减预期差 |
| `search_flash` | 仅即时研究 | 按关键词查找突发事件解释；不全量归档 |
| `search_news` | 仅即时研究 | 按关键词发现深度文章 |
| `get_news` | 仅即时研究 | 打开已选文章并引用标题、时间和URL |
| `get_kline` | 禁用 | 仅24小时、最多100根分钟线，不服务长期基金研究或状态历史 |
| `list_flash` | 禁用 | 全量快讯噪声高，容易造成数据膨胀和叙事偏差 |
| `list_news` | 禁用 | 全量文章流不进入项目数据仓 |

新闻不得转成自动情绪分、买卖信号或风险硬门禁。只有真正进入正式解释的事件才保留必要出处；不建立全文新闻库。

## 实测覆盖与限制

2026-09-13实测`quote://codes`列出97个品种，其中29个股票指数、15个商品、8个直接外汇和45个银行账户类产品。标普500、日经225、德国DAX、恒生、沪深300、黄金、WTI原油和美元兑离岸人民币均返回报价。

同日`list_calendar`返回本自然周226条记录，包含发布时间、重要性、实际值、预测值、前值、修正值和提供方影响文本。当前MCP只返回本周，不能据网站拥有长期历史推导出MCP可回填长期序列。

已知限制：

- 报价时间的交易所时区语义未公开；保留提供方时间并固定警告，陈旧值另行告警；
- 成交量单位未说明，因此不发布成交量；
- 名称元数据可能陈旧，例如`GDAXI`仍显示为DAX30；本地标签采用受审查映射；
- 没有VIX、美债完整期限结构、DXY、纳斯达克、全球宽度、跨市场资金流或指数长期历史；
- 远端服务版本、限频、SLA、修订和持久化条款未完整公开；缺少独立复核时保持`research_only`。

## 正式采集白名单

报价只保存精选11个代码的最新/收盘价和涨跌幅：`000300`、`HSI`、`SPX`、`FTSE`、`GDAXI`、`N225`、`XAUUSD`、`USOIL`、`USDCNH`、`USDJPY`、`EURUSD`。不保存OHLC和成交量，避免重复及未知单位。

财经日历只发布欧元区GDP/工业产出、德国工业产出、日本实际GDP/领先指标/经济观察家指数/核心CPI。观察日明确采用发布日，原经济统计期保留在标题中；在建立足够严格时点历史并冻结计算协议前，不接入`GlobalMarketStateSnapshot`评分。

## 数据流与安全

```text
Jin10 MCP → 不可变私有原始归档 → 状态/schema/代码/时间/数值门禁
          → 隔离市场数值表 → 即时状态或长期本地历史 → Agent解释
```

项目不保存Authorization头。token即使免费公开使用，也不得写入项目配置、日志、数据库、报告或Git。当前用户级Codex连接可供即时查询；本地采集CLI和自动维护进程从环境变量读取`JIN10_MCP_TOKEN`，受控启动脚本可从macOS钥匙串绑定该变量。工作日日频作业采集报价和本周日历；月度与季度发布由日历在发布日自然捕获，不重复建立远程作业。

## 回滚

1. 保持`jin10_policy.scheduler_status`为停用并移除未来作业条目；
2. 禁用项目或用户级Jin10 MCP；
3. 清理当前进程环境中的token；如token权限或使用规则未来变化，再在金十端轮换；
4. 保留既有私有归档作为审计记录，不删除或覆盖。
