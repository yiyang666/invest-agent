# 投资策略与631基准

## 投资目标

- 目标：长期资本积累与稳健增值；
- 月度新增资金：3,000元为稳定投入；另有0–2,000元机动预算，月度硬上限5,000元，目前没有5,000–8,000元的递增承诺；
- 不加杠杆，应急资金独立于本项目；
- 风险口径：15%目标控制线，约20%最大承受与压力线；
- 单基金上限25%，主题合计上限30%，主动再平衡每月最多2次。

正式参数以 `config/investment_policy.yaml` 为准。

固定定投基准每月只使用3,000元。机动预算不是默认投入，也不能仅凭“行情好”触发；它需要版本化策略信号或用户当月明确决定。任何使用机动资金的策略，都必须额外与“同月份、同总现金流”的631路径比较，避免把多投入本金造成的收益误判为策略增益。

## 冻结比较尺：631 v1.5

| 层级 | 比例 | 路由 |
|---|---:|---|
| 国内宽基核心 | 20% | 110020 易方达沪深300ETF联接A |
| 美国宽基核心 | 10% | 017641为代表路线；实际由购买路由池执行 |
| 英国宽基核心 | 10% | 539003 |
| 美国成长 | 10% | 000043 |
| 国内成长 | 10% | 019861 鹏华科创100ETF联接A |
| 防御 | 30% | 006932 平安0-3年期政策性金融债A |
| 被动科技卫星 | 10% | 160646 中证沪港深科技龙头指数路线 |

核心不等于低风险；沪深300、标普500和成长资产都可能深跌。631依靠30%防御、地域分散和仓位上限控制组合风险，而不是靠基金名称“看起来稳”。

### QDII购买路由（2026-08-25）

| 层级 | 比例 | 当前研究路线 |
|---|---:|---|
| 国内宽基核心 | 20% | 110020 |
| 美国宽基核心 | 10% | 017641/019305共享容量；096001独立补充；519981后备 |
| 英国宽基核心 | 10% | 539003 |
| 美国成长 | 10% | 000043 |
| 国内成长 | 10% | 019861；159259（027858代理）仅保留为未来短窗敏感性研究 |
| 防御 | 30% | 006932 |
| 被动科技卫星 | 10% | 160646 |

美国宽基以017641 A类标准标普500为主，019305 C类是共享日限10元的同基金替代份额；096001是独立的标普500等权路线，当前渠道日限10元、申购费0.15%；519981以最低1元、日限10元、申购费0.14%作为第四优先级后备。美国成长000043每日限购100元、申购费0.15%。英国宽基539003日限5,000元、申购费0.12%。

可买路线以 `config/qdii_purchase_route_pool_v1.json` 为准：仅接受开放或限购产品。只有独立限额才能合并容量；同一基金A/C份额的共享限额必须作为一个容量组。美国宽基容量缺口已由独立的096001路线补齐，但新版631仍须按“约三分之二标准市值加权、三分之一等权”实际暴露进行统一现金流回测，不能沿用纯标普500假设。

`dca_baseline@1.5.0` 已实现同袖套多路由、共享限额、优先级、独立费率和跨月队列。2024-01至2026-07反事实回测中，3,000元月供年化13.17%、XIRR 12.59%、年化波动10.32%、最大回撤-9.38%、平均现金拖累5.31%；旧v1.4比较尺分别为13.26%、12.52%、10.73%、-10.12%、5.12%。风险收益没有明显退化，因此v1.5已替换政策与注册表权威；五阶段慢熊压力为-20.80%，结论仍是“接近20%容忍边界、需要复核”，不代表生产门禁通过。

## 三个不同概念

1. `allocation_anchor_631`：长期目标比例，不要求每天严格等于631。
2. `dca_baseline@1.5.0`：631加上月度预算、目标缺口、多路由限购队列和5/15/25扣款规则，是公平比较尺。
3. `tactical_overlay`：可改变新增资金时点或袖套路由，但必须先有规格、匹配现金流对照和风险否决。

因此未来可以出现“核心定投、卫星按回撤分批投入”，但不能把执行偏离偷偷改写成新的长期配置。

## 关键研究结论

- 000043与美国宽基相关性较高；纳指类资产是美国成长倾斜，不是独立分散。
- 019861和160646波动较高，不能因阶段景气度提高长期上限。
- 006932承担防御与适度增值职责，不等同于现金或应急资金。
- 160646已由鹏华官网和东财共同核验1,137个净值日，数值冲突为0；历史公告可见时点仍不完整。
- 现有历史已经参与选型，不能重新命名为样本外；前瞻观察至少需要12个完整月。

## 行为纪律

- 盈亏颜色、短期涨跌和后悔情绪不能单独触发交易；
- 真实回撤10%开始复核，15%重点复核，接近20%停止增加风险；
- 复核不等于赎回，风险修复优先分阶段降低集中度和补齐防御；
- 任何真实交易逐笔确认，当前系统继续 `advisory_only`。
