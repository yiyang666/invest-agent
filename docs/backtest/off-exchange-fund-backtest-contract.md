# 场外基金回测契约 v0.1

## 1. 基本原则

回测必须是确定性的事件模拟，不得把场外基金当作按收盘价立即成交的股票。每次运行绑定策略版本、数据批次哈希、规则版本、参数和代码版本。

## 2. 数据可见性

- 净值记录同时区分 `nav_date`（净值所属日）和 `ann_date`（可被投资者看到的公告日）。
- 因子只能使用当时已经公告的数据；供应商后来修订的数据不得反向进入旧时点。
- 使用单位净值加分红事件，或使用复权净值计算总收益，二者只能选一种，不得重复计入。
- QDII 使用产品自己的估值/开放日历和净值延迟，不能直接套用 A 股交易日历。

## 3. 订单与净值归属

- 定时定额等不依赖当日收盘净值的预先计划，可按基金规则在截止时间前提交，并使用对应开放日净值。
- 若信号依赖当日收盘后才公布的净值，则最早只能在下一可申购开放日提交，禁止用同日净值成交。
- 截止时间之后、周末、节假日或非开放日的申请顺延到下一有效开放日。
- 暂停申购、单日限额、最低金额、锁定期和巨额赎回必须产生明确的拒绝、截断或延期事件。

## 4. 申购模型

对于比例前端申购费，默认公式为：

```text
net_subscription = gross_cash / (1 + purchase_fee_rate)
purchase_fee = gross_cash - net_subscription
confirmed_shares = round_by_rule(net_subscription / execution_nav)
```

固定费用、渠道折扣和后端收费按基金当时有效规则覆盖。现金从提交开始进入在途状态，份额在登记确认后可用。

## 5. 赎回模型

```text
gross_redemption = redeemed_shares * execution_nav
redemption_fee = gross_redemption * fee_rate(holding_days, share_class, rule_version)
net_cash = gross_redemption - redemption_fee
```

赎回费率按每批份额持有期计算；批次消耗顺序必须由产品/登记规则确认并配置。赎回提交、确认和到账是不同事件，到账前资金不可再投资。

## 6. 费用边界

- 基金净值已经扣除了从基金资产计提的管理费、托管费和适用的销售服务费，回测不得再次逐日扣除。
- 申购费、赎回费、转换费及销售渠道折扣在投资者现金流层单独建模。
- A/C 等份额类别必须视为不同工具；不能只根据基金名称合并。
- 规则必须支持生效日期，因为法规、招募说明书和渠道折扣会变化。

## 7. 分红与份额事件

- 现金分红进入现金账户；红利再投资按照基金公告规则折算份额。
- 拆分、合并、份额折算不得被误判为投资收益。
- 复权净值与显式分红事件的总收益结果应在容差范围内一致，否则数据批次失败。

## 8. 组合与异步执行

同一组合中的基金可以共享目标权重或策略信号，但不能共享一个虚构的成交时点。每只基金分别执行自己的开放日、截止时间、限额、净值确认和到账规则；组合在任一时点都必须保留现金、在途申购、可用份额、在途赎回四类状态。

## 9. 最低输出

- 时间加权收益、资金加权收益/XIRR、年化收益
- 最大回撤、回撤持续期、修复期、波动率
- 费用、换手、现金拖累、拒绝/延期订单
- 与定投基准和静态配置基准的差异
- 样本内、样本外、walk-forward 和参数敏感性
- 每一笔模拟订单的信号时点、提交时点、净值日、确认日、到账日和使用规则版本

## 10. 验收场景

至少覆盖：截止时间前后、周末顺延、QDII 节假日差异、申购限额、暂停申购、短期赎回费、分批申购后的赎回、现金/红利再投资、净值修订、缺失净值和数据源冲突。

## 11. 规则依据

- [《证券投资基金法》](https://www.csrc.gov.cn/csrc/c101939/c1045353/content.shtml)：申购、赎回价格依据申赎日基金份额净值加减费用计算。
- [《公开募集证券投资基金运作管理办法》](https://www.csrc.gov.cn/csrc/c106256/c1653978/content.shtml)：申赎成立、生效、确认和赎回款支付属于不同阶段，具体方法由基金合同和招募说明书约定。
- [《公开募集证券投资基金销售费用管理规定》发布说明](https://www.csrc.gov.cn/csrc/c100028/c7606047/content.shtml)：2026 年起销售费用规则已调整，因此费用规则必须按生效日期版本化。
- [招募说明书内容与格式准则](https://fg.amac.org.cn/governmentrules_3854/zcgz_gfxwj/gfxwj_gmjj_xxpl/202003/t20200312_24751.html)：开放日、时间、申赎价格和份额净值计算方式应在产品文件中披露。
