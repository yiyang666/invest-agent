# Phase 4 科技成长袖套回撤执行回测 S3.6

## 结论

`sleeve_drawdown_recovery@1.0.0`在2024-01至2026-07的31个月场外执行研究中领先四个对照，但领先幅度较小、样本很短，且结果明显受2024年以来科技成长修复影响。结论为`implemented / research_only / promising_but_insufficient`：保留研究，不替代631，不进入生产。

## 策略与风险边界

- 每月基础3,000元仍按631目标缺口分配；
- 539001、019861、160646任一袖套相对126观察日高点回撤达到10%/15%/20%，额外预算分别为500/1,000/2,000元；
- 额外预算先尝试在触发袖套之间等分，但科技成长合计不得超过30%，单基金不得超过25%；
- 超出容量的额外预算自动转入110020与050025，各50%；
- 完整631组合回撤达到20%时否决全部袖套追加；不卖出、不借款、不动应急资金。

前6个月因019861共同历史不足而保持基础投入。其后12个月触发额外预算：10%档8次、15%档2次、20%档2次，共增加10,000元。完整组合没有触发20%风险否决。

## 为什么仍不能晋级

1. 可执行共同区间只有31个月，缺少完整牛熊周期；
2. 12次触发并非12个独立市场周期，主要集中在019861的2024修复及随后数次科技回调；
3. 历史净值公告可见时间仍是假设口径；渠道费率和动态限额也不是逐日官方历史；
4. 领先同月宽基追加仅159.14元，容易被未来费用、限额变化和路径差异吞没；
5. 没有完成冻结后的前瞻样本外观察。
