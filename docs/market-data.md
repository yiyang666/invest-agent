# 市场状态数据契约

市场数据层目前接收四类证据：股叉叉的估值/利率/汇率/杠杆/宏观/拥挤及公开总览页的全A股聚合宽度，经过基金门禁的指数基金净值代理，以及FRED个人研究范围内的NFCI。上交所沪市横截面采集器保留为手工校验能力，不再承担日常宽度主链路。它们都不直接预测涨跌，也不直接生成策略信号或订单。

## 数据流

```text
股叉叉MCP与公开总览 / FRED公开下载 / 本地基金校验仓
                 ↓
      原始或派生输入归档 → schema/日期/单位/完整性门禁
                 ↓
      市场数据隔离表 → 确定性状态/风险 → Agent解释
```

即时聊天查询可以不持久化，但不得进入正式报告。任何进入风险、策略、回测、归因或调仓建议的数据必须先形成`evidence_snapshot`。需要历史分析的序列必须由本地仓供数。

## 数据族

| 数据族 | 工具 | 本地形态 | 计划频率 |
|---|---|---|---|
| 指数估值 | `get_index_valuation` | 数值时间序列；保留指标、窗口和计算口径 | 周频、月末 |
| 指数权重 | `get_index_weight` | 成分权重快照；显式保留`is_estimated` | 月末T+1 |
| 指数前瞻 | `get_index_forward_pe` | 带覆盖率和预测年度的版本化快照 | 周频、月末 |
| 行业拥挤 | `get_industry_crowding` | 行业×角度周频观察 | 周频 |
| 市场序列 | `get_market_series` | 国债、外汇、两融数值序列 | 工作日 |
| 宏观序列 | `get_macro` | CPI/PPI/PMI/非农/月度指标及GDP季度指标 | 月频、季频 |
| 可投资趋势代理 | `publish-fund-proxies` | 中、港、美、欧、日代表指数基金累计净值；保留代理缺陷 | 工作日；历史首次回填 |
| 金融条件 | `collect-fred --series NFCI` | FRED原始CSV及NFCI周频序列 | 周频 |
| 全A股宽度 | `collect-guchacha-breadth` | 股叉叉公开总览HTML及全A上涨/下跌/平盘、有效分母、上涨占比、ADR、平均涨跌幅 | 工作日收盘后 |
| 沪市宽度校验 | `collect-sse-breadth` | 上交所沪市日终横截面与派生宽度；不在默认计划中 | 手工按需 |

## 必需字段

所有批次记录`batch_id/provider/tool/arguments/fetched_at/as_of/raw_sha256/schema_sha256/quality_status`。数值观察至少记录`series_id/observation_date/value/unit/frequency/first_seen_at/visibility_status/batch_id`。不知道的单位、日期、发布时间或口径保持未知并阻断发布，禁止由Agent猜测。

## 时点和修订

- 实时采集到的当前值记录`first_seen_at`，只能从该时点之后使用；
- 远端返回的旧历史没有可信发布时间时标为`historical_visibility_assumed`；
- 指数当日预估权重不能冒充T+1官方权重；
- 前瞻盈利和宏观历史可能修订，同一观察日的新值追加版本，不覆盖旧批次；
- 远端历史接口只用于回填和研究，不能自动获得严格样本外资格。

## 发布门禁

应用层错误、空结果、非有限数值、未知单位、未来日期、重复冲突、schema漂移或原始响应不能重放时拒绝发布。跨来源差异保留两条记录，不平均、不静默选值。当前独立第二来源不足的数据只能进入`research_only`市场背景，不能成为风险硬否决或策略信号。

网页/公开下载不是通用fallback。只有数据源清单和来源评审中逐项批准的固定来源可以自动运行；禁止登录cookie、验证码/反爬绕过、代理轮换和未经审查的换源。FRED、股叉叉聚合宽度与上交所校验数据仅限用户个人本地研究并保留引用，原始文件不进Git。项目不直接归档东方财富全量行情；股叉叉页面只发布聚合结果，并显式记录其页面所称上游与未分类证券数量。
