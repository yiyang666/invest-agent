# ADR-0037 本机网页配置第三方接口钥匙串凭证

日期：2026-10-10；状态：接受。

## 背景

股叉叉与金十 MCP 的本地采集需要 Bearer token。让用户把令牌发送到 Agent 对话，再由 Agent 写入环境或钥匙串，会让秘密进入不必要的交互链。把令牌写入项目配置、数据库或私有明文文件也会扩大泄漏面。

## 决策

本机 Web 新增“接口配置”，仅接受固定提供方 `guchacha` 与 `jin10`。浏览器以同源 JSON 请求把令牌直接交给回环 Web 服务，服务通过 macOS `security` 的标准输入写入当前用户登录钥匙串，服务名固定为 `invest-agent-guchacha-mcp` 和 `invest-agent-jin10-mcp`。页面保存成功后立即清空输入框；状态接口复用原脚本的只读可用性检查并丢弃输出，只返回已配置、未配置或需要解锁/授权，不显示或返回密文。

令牌长度限制为 8–4096 个字符，拒绝空白和控制字符。请求体上限为 8 KiB，只接受 `application/json`，提供方不能由调用方扩展。既有 Host 与 Origin 检查继续生效。服务器不记录请求体，错误响应只返回固定错误码。

该页面只承担首次部署和后续更换 token，不参与日常数据更新。既有基金与市场维护脚本保持不变：进程环境变量存在时优先使用，否则从固定钥匙串服务名读取。保存页面关闭、Web 服务停止或项目代码更新，都不影响已经写入钥匙串的配置。令牌不进入项目配置、SQLite、原始归档、日志、测试快照、报告或 Git。

登录钥匙串锁定或当前会话不允许交互时，保存失败关闭并提示用户在本机解锁后重试；不得回落到明文文件。页面不提供显示、复制或导出已保存令牌的能力。

## 边界

接口配置不会修改 MCP 允许列表、数据用途、更新频率或工具权限，也不会测试未审查工具。它只解决已审查提供方的本地凭证交付。ADR-0036 中“服务端不接受凭证输入”的限制由本决策对这两个固定配置接口作窄范围替代；交易凭证和账户凭证不在此页面范围内。
