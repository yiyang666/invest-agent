# ADR-0017：当前合同决定基金历史边界

- 状态：有效
- 日期：2026-08-25

## 背景

同一基金代码可能在基金转型后继续使用。若按代码抓取全部历史，会把旧合同下不同投资目标、范围和比较基准的净值拼接到当前基金身份，污染收益、波动、回撤、相关性和回测。

`539003` 是已确认案例：代码在“建信全球资源混合型证券投资基金”转型为“建信富时100指数型证券投资基金（QDII）”后保持不变，新合同自 2020-01-10 生效。

## 决策

1. 完整历史回补必须存在版本化、可审计的当前合同起始日；请求起点取该日期，不能取代码最早净值日。
2. 没有已核验合同边界的基金只执行受限近期回补，禁止模型推断或以基金成立日冒充当前合同起点。
3. 合同边界前的已归档观测不删除，但本地数据服务层自动从当前身份的指标序列中排除。
4. 回补完成状态绑定基金代码、数据源和合同起始日；合同边界变化会触发新一轮回补。
5. 回补完成后的工作日任务继续使用重叠增量更新。
6. 合同核验是新基金的一次性准入事项；工作日净值同步只读取本地登记并报告待核验清单，不搜索合同网页、不解析 PDF、不调用模型。

## 结果

历史数据继续可审计，但研究序列不再默认假设基金代码对应的经济身份永久连续。新增基金若要自动完整回补，必须同步补充权威合同边界；否则系统失败关闭到最近窗口。
