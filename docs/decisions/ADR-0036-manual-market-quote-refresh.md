# ADR-0036 本机网页人工刷新已审查市场报价

日期：2026-10-10；状态：接受。

## 背景

总览需要提供有时效性的宏观市场参考。既有 ADR-0034 将首版本机网页限定为本地只读视图，既有 ADR-0032 已允许金十精选跨资产报价进入正式本地市场数据链。直接从网页接入新的行情站点会绕过来源审查、原始归档和质量门禁，也会让展示层承担数据源切换逻辑。

## 决策

本机网页增加唯一的远程数据动作 `POST /api/market-refresh`。该动作只接受同源、零请求体的回环请求，并只执行固定脚本 `scripts/refresh_market_quotes.sh`。脚本调用 `invest_agent.market_data.cli collect-jin10-quotes`，沿用配置中的报价允许列表、单次请求、原始归档、标准化、质量门禁和本地发布流程。服务端不接受工具名、指数代码、命令参数或凭证输入，也不向浏览器返回采集进程输出。

总览只读取通过门禁的本地 `jin10_quote:*` 序列，当前展示沪深300、恒生、标普500、富时100、德国DAX和日经225。涨跌点数由当前点位与提供方涨跌幅确定性反算并在页面注明。刷新失败时保留并继续展示已有本地报价，不生成模拟值。

股叉叉和雪球只作为人工打开的外部链接。网页不自动抓取雪球，不使用未审查的东方财富全量行情，也不把基金净值代理标成实时指数。上证指数、创业板指、科创50和纳斯达克在取得并审查合适来源前保持缺失。

## 安全与架构边界

该接口不查询账户、不修改基金或持仓数据、不运行策略、风控、决策或回测，也不构造订单。数据库视图仍以只读连接读取；市场数据写入只发生在既有采集 CLI 内。网页继续只监听 `127.0.0.1` 并执行 Host 与 Origin 检查。凭证只从环境变量或 macOS 钥匙串读取，不进入请求、日志、Git 或页面响应。

本决策只对 ADR-0034 的“无远程采集接口”作窄范围修订，其余只读研究与无交易边界继续有效。
