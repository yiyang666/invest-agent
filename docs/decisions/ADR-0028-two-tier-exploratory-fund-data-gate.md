# ADR-0028：代表基金探索门与晋级门分离

- 日期：2026-08-26
- 状态：有效
- 范围：research_only strategy discovery and backtest
- 实盘影响：无；不改变真实交易权限或逐笔确认要求

## 背景

复杂组合策略在第一次机制检验前就逐只追溯基金合同沿革、历史销售渠道规则、风格漂移和全部申赎精度，会把大部分成本花在尚未证明有效的策略上。另一方面，直接忽略基金身份、净值质量、未来数据和现金守恒，又会让回测失去基本可信度。

本项目因此把“能否运行探索回测”和“能否晋级为候选策略”拆成两个不同门禁。探索门回答机制是否值得继续；晋级门才回答证据是否足以支撑注册、月度建议或更高风险用途。

## 决策

### 1. `research_ready` 探索门

代表基金满足以下条件后，可以进入带明确标签的探索回测：

1. 基金代码、份额类别、经济暴露和所属袖套已核对，且没有已知身份断裂污染所用窗口；
2. 回测使用已归档、经质量检查并发布到本地校验仓的净值，不在运行时直接读取远端网页；
3. 当前可购状态、最低金额、限额和费用来自用户观察或已审查渠道的只读查询，并保存脱敏、可复核的归一化快照；
4. 历史渠道规则未知时，必须把当前规则外推标记为 `counterfactual_execution`，并至少保留法定费率或零折扣费用敏感性；
5. 尚未接入的估值、宏观或组合因子按阶段排除对应变体，不得用中性值或模型猜测填补；
6. 结果标记为 `exploratory`、`short_window_only` 或相应代理证据等级，不得进入策略注册表或月度建议入口。

探索门暂不要求逐只完成：完整合同变更年表、长期风格漂移检查、全部历史渠道有效日期、平台专属精确份额取整、产品级退出否决和完整压力映射。这些项目可以在策略机制显示出继续价值后再补。

以下问题即使在探索门也仍然阻断：基金/份额身份错误、所用窗口内已知重大身份断裂未切边界、净值质量失败、未来数据泄漏、现金或份额不守恒、缺失因子被静默填造，以及把不同经济暴露自动替换为同一袖套。

### 2. `complete` 晋级门

策略要注册为 `research_candidate`、进入月度建议或申请任何执行权限，发现报告必须升级为 `complete`。届时需要补齐与策略实际动作相关的有效日期化产品规则、费用和结算语义、压力映射、数据点时可见性、实现与测试，并重新评审合同变化、基准/风格漂移和代表基金适用性。

探索结果不能仅因收益较好自动跨过晋级门，也不能在原文件上抹去反事实和短窗口标签。

### 3. 爱基金只读渠道证据

已审查的 `aijijin/thsfund` CLI 可用于：

- 公共只读 `fund fee-rule`；
- 受保护但不提交订单的 `fund subscribe-init`，且仅提取基金身份、可购状态、最低/最高金额、剩余额度、费用折扣和平台展示的确认/到账字段。

不得通过 `fund buy`、`fund redeem`、撤单或任何“假提交/试单”骗取规则数据。受保护响应中的账户、客户、支付方式和凭证字段不得写入仓库；只保存白名单字段的脱敏快照。

## 公平性解释

使用同一只代表基金、同一净值和同一反事实渠道规则，可以公平比较候选策略内部的消融版本，回答“红绿灯、目标缺口或风险预算本身是否增加价值”。

它不会自动使候选策略与631完全同质。与631比较仍必须统一起止日、外部现金流、可见数据截止和费用情景，并分别披露基金选择、限额和短历史带来的基差。探索阶段的结论是“在这些代表基金和假设下值得或不值得继续”，不是未来收益承诺。

## 后果

- `hierarchical_risk_budget_valuation@0.2.0` 可先按A1固定40/20/40、A2卫星买入型红绿灯等不依赖延期因子的阶段推进；
- D4估值和组合波动版本在数据发布前保持 `variant_excluded`，不得阻塞A1/A2，也不得获得虚构信号；
- 当前爱基金规则快照可以用于研究费用/限额/到账的反事实回放，但不证明历史上每天都适用同一规则；
- 真实申购、赎回、撤单和自动交易仍完全受既有Execution安全门约束。
