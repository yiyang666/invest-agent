# ADR-0021：Phase 6模拟审批与执行收口

- 日期：2026-08-25
- 状态：accepted
- 范围：Phase 6，mock only

## 决策

Phase 6工程闭环完成。批准消费与 `submitting` 状态必须在同一个SQLite事务中提交；事务提交前崩溃，两者一并回滚；提交后进程中断，重启时把残留 `submitting` 转为 `unknown`，对账完成前禁止再次提交。

模拟执行日志只保存订单摘要、批准ID、状态和时间戳，不保存基金、账户、支付信息或凭证的明文。交互式演练要求输入完整 `APPROVE MOCK <intent_sha256>`，普通“确认”“继续”无效。

Phase 6收口不启用真实交易。真实申购属于Phase 7，必须重新经过本轮只读预检、支付方式选择、协议阅读、项目级精确订单摘要与逐笔最终确认。

## 验收

- 崩溃前后的事务边界可重复验证；
- 重启和并发不会造成重复消费或重复模拟提交；
- `unknown` 只能对账为 `submitted` 或 `failed`；
- CLI演练和数据库均无网络与外部副作用；
- `config/phase6_closure_audit_v1.json` 全部检查为真，生产实盘仍阻断。
