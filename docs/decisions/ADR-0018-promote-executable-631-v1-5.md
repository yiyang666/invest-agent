# ADR-0018：采用可购买路线的631 v1.5

- 日期：2026-08-25
- 状态：accepted for research benchmark and personal target
- 模式：research_only / advisory_only

## 决策

将 `dca_baseline@1.5.0` 设为唯一的比较基准与个人长期配置参考。长期层保持60%，拆分为国内宽基20%、美国宽基10%、英国宽基10%、美国成长10%、国内成长10%；防御30%；沪港深科技卫星10%。

国内成长采用 `019861`（科创100路线）。`159259`/`027858` 的全市场成长定义保留为未来短窗敏感性研究，不进入当前权威基准，因为可用历史不足以支撑同等强度的完整回测。

美国宽基通过版本化购买路由池实现，当前以 `017641` 为代表路线，并受共享日限额约束；英国宽基采用 `539003`；美国成长采用 `000043`。任何产品替换、权重改变或限额语义改变都必须产生新版本，不能静默改写本基准。

## 证据

2024-01-02 至 2026-07-31 的本地复现回测（每月3000元）得到：年化收益13.17%、XIRR 12.59%、年化波动10.32%、最大回撤-9.38%、平均现金拖累5.31%、期末109,308.36元。结果来自 `data/private/reports/dca-baseline-v1-5-route-pool-candidate-20260825-r2.json`，仅属于历史可见性假设下的研究证据。

标准慢熊压力路径达到约-20.80%，因此风险结论为“接近20%容忍边界，必须复核”，不是通过生产门禁，也不是收益目标。基准仍可作为比较尺和目标配置；任何当期建议仍受独立风险层否决。

## 后果

- `dca_baseline@1.4.0` 封存为历史比较版本，不再拥有目标配置权限。
- v1.5 的前瞻样本外观察时钟重新开始；历史窗口不能冒充样本外验证。
- 系统保持无杠杆、只研究、不生成订单意图、不提交真实交易。
