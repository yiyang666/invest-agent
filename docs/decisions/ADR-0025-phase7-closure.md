# ADR-0025：Phase 7逐笔受控申购收口

- 日期：2026-08-26
- 状态：accepted
- 范围：真实申购批准、执行日志与对账

## 决策

Phase 7工程收口。首笔006932申购已由基金公司确认，订单确认份额与实时持仓一致。后续真实申购继续采用逐笔受控模式，不开放无人值守或策略自动下单。

`PersistentControlledLiveGateway`只承担确定性门禁：将基金、金额、脱敏账户、支付方式、费用、协议记录和预计结果绑定为精确摘要；15分钟批准只能消费一次；消费批准与写入`submitting`在同一事务；单笔、单日、单月额度在同一事务校验。重启后残留`submitting`转为`unknown`，对账前不得再次提交。

数据库仅保存摘要、必要的额度累计值、时间和外部订单号哈希，不保存基金、账户、协议编号、外部订单号或凭证明文。网关不直接调用爱基金CLI，真实提交仍由受审查流程在当轮明确确认后单次执行。

赎回和撤单权限继续关闭；只读`redeem-render`仅用于规则核验。任何网络超时、5xx或状态异常都禁止自动重试。
