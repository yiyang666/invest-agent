# ADR-0031：受控公开下载与长期本地历史

- 状态：有效
- 日期：2026-08-29
- 更新：2026-08-30（全A聚合宽度替代默认沪市横截面）

## 决策

市场数据不再使用“是否允许爬虫”这一个布尔问题判断。每个远端数据族必须单独冻结来源、URL、用途范围、访问频率、存储许可、字段契约、超时、重试、schema漂移和第二来源计划。

允许的自动采集必须同时满足：公开且无登录、无需绕过技术措施、来源条款允许当前个人研究和本地保存、固定低频请求、无自动重试、原始先归档、质量门禁后发布、Git不提交原始数据。cookie借用、代理池、反爬绕过、验证码破解和运行时自动换源一律禁止。

FinClaw的`efinance/akshare/adata/Ashare/snowball`只作为接口地图逐项评审，不能按包名计算来源多样性。东方财富指数/全量行情因现行协议的行情复制限制不进入本地市场仓；雪球因官方条款明确禁止自动抓取、存储和AI用途而继续拒绝。

在官方指数许可未满足前，趋势轴可使用已经通过基金数据门禁的可投资指数基金累计净值作为显式代理。代理必须保留基金代码、源批次和哈希，并标记跟踪误差、费用、汇率和净值滞后，不得称为官方指数。2026-08-30起，华夏恒生ETF联接A（000071）作为香港恒生指数人民币净值代理；它不替代官方指数，也不自动进入购买候选。

FRED公开CSV下载的NFCI只用于用户个人本地研究，保留引用、禁止再分发。旧历史没有原始发布日期时标为`historical_visibility_assumed`；上线后每次首次观察的最新值记录`first_seen_at`。

上交所官网行情页使用的公开日终端点符合固定公开来源条件，批准低频个人研究采集。适配器必须一次取回完整横截面、只接受15:00及之后的收盘快照、排除B股和无有效收盘价的证券、保留原始响应并从首次成功采集日起积累`strict_point_in_time`历史。输出名称必须是“沪市A股宽度”或“部分中国宽度”，不得写成“全A股宽度”；深市和北交所另行评审。

后续评审发现股叉叉公开总览页已经以服务端HTML直接发布全A股总数、上涨/下跌/平盘家数、平均涨跌幅和收盘后同步时间。默认日频链路改为一次抓取该聚合页，不建立逐股行情仓。页面报告的总数与涨跌平合计不一致时，系统保留未分类数量，并以涨跌平合计作为上涨占比分母。上交所适配器继续保留为手工校验能力，但移出默认bootstrap和日频任务。

## 理由

- Python库的开源许可证只覆盖代码，不覆盖上游行情权利；
- 固定来源与原始归档比自动fallback更适合重放、风控和点时审计；
- 代理数据可以在不伪造权威性的前提下先补研究覆盖；
- 从上线日起长期积累严格时点历史，能逐年提升系统证据质量，但不会自动产生预测能力。

## 后果

- 新增FRED与上交所宽度raw-first适配器、基金净值代理发布器及统一维护操作；
- `GlobalMarketStateSnapshot@0.5.0`接入中港美欧日趋势/回撤代理、美国就业周期代理、NFCI、全A聚合宽度、主要市场估值和行业拥挤分布，仍为`research_only`；
- 网页采集的生产总开关继续关闭，只有数据源清单中逐项批准的个人研究适配器可运行；
- 原始数据和快照只存私有忽略目录，公开仓库仅提交代码、配置和条款说明。
