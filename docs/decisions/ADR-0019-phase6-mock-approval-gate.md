# ADR-0019：Phase 6只实现模拟审批门

- 日期：2026-08-25
- 状态：accepted
- 范围：Phase 6.1，mock only

## 决策

Phase 6首先实现与外部交易隔离的订单草案、一次性人工批准和模拟状态机，不接入爱基金申购、赎回或撤单接口。

每个订单草案必须完整绑定基金代码、动作、金额或份额、脱敏账户别名、预计费用和预期结果。批准只绑定该草案的规范化SHA-256，15分钟后失效，只能消费一次；任何关键字段变化都会产生新摘要并使旧批准无效。

模拟提交若进入 `unknown`，在显式对账前禁止再次提交。网络、超时、5xx或响应异常不得自动重试。mock结果不得被描述成真实订单状态。

## 安全边界

- `real_adapter_allowed=false`，不得导入或调用 `aijijin` 买卖命令。
- 不保存完整账户号、支付凭证、token或设备标识。
- 本阶段只验证门禁和故障处理，不赋予任何真实交易权限。

## 验收

- 精确草案可被一次性批准并在15分钟内消费；
- 改金额、基金、账户、费用或预期结果后旧批准失效；
- 过期批准、重复消费、未知状态重试全部失败关闭；
- 对账后才能结束未知状态；
- 全部输出明确标记 `mock_only`、`real_trading_enabled=false`。
