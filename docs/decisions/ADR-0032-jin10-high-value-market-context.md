# ADR-0032：金十数据仅接入高价值市场背景

- 状态：有效
- 日期：2026-09-13

## 决策

金十MCP作为股叉叉和本地基金代理的补充，只承担跨资产即时报价、欧洲/日本关键经济发布及按需事件解释。

正式采集只允许`get_quote`和`list_calendar`。即时研究只允许`search_flash`、`search_news`和`get_news`。`get_kline`、`list_flash`和`list_news`关闭：分钟线不符合长期场外基金系统的时间尺度，全量资讯流会增加噪声、版权负担和系统复杂度。

报价只发布受审查代码的最新/收盘价与涨跌幅；成交量因单位不明不发布。财经日历只发布有明确单位和标题映射的欧洲、日本关键宏观值及实际减预期差。所有正式值先原始归档、再校验和写入隔离市场表；新闻只作解释，不能生成预测、策略、风险批准或订单。

金十自动作业纳入现有`market_daily_series`：每个工作日采集精选报价和本周财经日历。日历中的月度、季度指标按实际发布日期入库，因此不为金十另建周/月/季远程作业。用户已确认当前token为公开免费使用，但项目仍不保存token；固定会话通过受控启动脚本从环境变量或macOS钥匙串绑定`JIN10_MCP_TOKEN`。不建立新会话或独立调度器。

## 理由

- 金十的优势是及时的全球报价和经济事件，不是长期历史、估值、宽度或资金流；
- 精选面板能补当前状态的新鲜度，按周经济日历可以从上线日起积累欧日严格时点历史；
- 分钟线和全量新闻与用户的长期基金投资目标不匹配；
- 先冻结用途和白名单可以防止新会话把资讯热度误当量化信号。

## 后果

- 新增Jin10受审查适配器、CLI、重放和统一维护操作；
- `GlobalMarketStateSnapshot@0.5.0`暂不改权重或覆盖率；欧日宏观历史达到要求后另行版本化；
- 现有数据更新总控增加两个日频操作；周/月/季只在本地按观察频率聚合，不重复请求金十。
