# ADR-0033：月度决策以一页结论为默认入口

- 日期：2026-10-09
- 状态：有效

## 决策

日常月度复核先阅读“现状、风险、行动草案、理由与下次复核”一页结论。该页面只从已通过流水线门禁、哈希校验的当月研究报告生成；现有决策包、证据报告、解释验收和 Manifest 继续作为完整审计材料。

一页结论不得生成订单或替代投资政策。缺少当月 Manifest、报告哈希不符、流水线未通过或报告含订单时，入口失败关闭。每月仍需新的账户快照、数据截止日和独立风险判断；不把旧月配置自动改日后复用。

## 理由

现有多阶段研究链能审计，但日常入口过长，且固定在 2026 年 8 月的配置容易被误当当前结论。一页结论让用户先看到可行动的判断，再按需追溯完整证据；当月证据不足时直接说明无法生成。
