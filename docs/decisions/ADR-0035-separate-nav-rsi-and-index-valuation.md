# ADR-0035：分离净值 RSI 与指数估值分位

- 状态：有效
- 日期：2026-10-10

## 决策

基金详情页把累计净值走势与净值波动指标拆成两幅图。净值波动使用本地已发布累计净值按 Wilder 14日 RSI 确定性计算，固定输出 0—100：低于30显示低位区，高于70显示高位区，其余显示中位区。时间范围按钮只裁剪图形，不重新计算 RSI。

不再把所选区间内当前净值的最低—最高相对位置称为分位或估值。跟踪指数 PE TTM 五年分位属于独立市场估值数据；在完成基金到指数的时点映射、历史数据归档和质量门禁前，网页不推算、不用净值替代，也不把 RSI 标作估值。

## 理由

- 原实现对所选时间窗的净值跨度做三等分，既不是经验分位，也会被极值、分红和查看区间改变。
- RSI 描述近期上涨与下跌力量；指数 PE 历史分位描述底层资产相对估值，两者输入、窗口和含义不同。
- 累计净值比单位净值更适合连续收益路径分析，可减少分红造成的假跌落。
- 本地逐点计算可复现、可测试，并避免浏览详情时调用外部接口。

## 后果

- `GET /api/nav` 增加 `display_nav` 和 `rsi_14`，仍只读取通过门禁的本地净值。
- RSI色带仅供观察，不生成申购、赎回或调仓信号。
- 后续若引入同花顺 `rsi_pct` 或指数估值字段，必须经采集、归档、校验和对照测试后作为独立字段接入。
