# ADR-0022：Phase 7受控实盘入口保持禁用直至逐笔确认

- 日期：2026-08-25
- 状态：proposed
- 范围：Phase 7准备

## 决策

用户允许项目开始接入真实申购能力，但“可以大胆测试”不是任一订单的最终批准。撤单能力不能作为申购安全保障：提交状态、渠道受理、时间窗口或网络异常都可能使撤单不可用。

首个实盘范围只考虑单笔申购并立即查询订单详情，不自动撤单，不自动重试。提交前必须使用当轮 `subscribe-init`、`fee-rule`、风险和身份结果，由用户明确选择支付方式、阅读协议，并由项目展示包含基金、金额、脱敏支付账户、费用、协议记录和预计确认信息的精确摘要。随后取得只对该摘要有效、15分钟一次性的最终确认。

Phase 7策略草案位于 `config/phase7_controlled_live_policy_draft_v1.json`。在用户确认硬上限、真实适配器审查和仓库政策版本化完成前，`real_trading_enabled` 保持 `false`，不调用 `aijijin fund buy` 的联网模式。

## 风险额度

- 长期绝对单笔、单日和单月上限均为5000元，但任何订单不得超过当月剩余额度；
- 不限额基金继续按5/15/25三次申购，限购路线可按容量尽快填满；
- 每笔订单必须与已批准调度计划一致，静态上限不替代计划门禁；
- 首笔实盘试运行临时限制为一笔、最多500元，且不自动撤单。

原拟“单日1000元”会在5000元月供、目标缺口集中或多基金同日扣款时误伤合法计划，因此撤回。上述数值是待用户确认的工程硬门，不是投资建议或自动投资额度。
