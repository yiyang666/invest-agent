# ADR-0016：QDII购买路由与研究/持仓监控分离

- 状态：有效
- 日期：2026-08-24
- 范围：QDII购买候选、限额队列和数据刷新

## 背景

QDII基金可能在不同渠道处于开放、限购、暂停或不支持交易状态。把“适合作为研究标的”“账户仍持有”和“现在能够买入”混成一个观察池，会让建议引用无法执行的基金，也可能因停售而停止监控已有风险。

## 决策

1. 建立独立、版本化的购买路由池。只有当前渠道状态为 `open` 或 `limited` 的基金可以进入 `purchase_candidates`；`suspended`、`unsupported`、`closed` 和 `unknown` 一律拒绝。
2. 暂停或不支持交易的基金可保留为回测参考，但必须位于 `blocked_or_reference_routes`，且不得生成新增资金建议。
3. 账户仍持有的基金无论能否继续购买，都进入每日净值与风险监控。停售不能让已有持仓从风险视野中消失。
4. 同一袖套可登记多个经核验的开放/限购路由。限购容量按路由和交易日累加，未完成预算允许跨日、跨月排队，直至达到该袖套预算或用户停止计划。
5. 系统不自动替换基金。新增路由、状态或限额变化必须带来源、时点并通过版本化复核。
6. 路由池只计算可实施容量，不改变631研究基准，不生成订单，也不解除 `advisory_only`。

## 当前落地（2026-08-25渠道复核后）

- 美国宽基袖套登记摩根标普500的两类份额：017641 A类当前申购费0.12%，019305 C类申购费0。用户进一步核验确认，A/C并非独立容量，而是每天只能选择一类购买10元，因此两条路线共用10元日限额。
- A类为长期优先路线，C类仅为同日互斥的替代路线；两者既不增加资产分散，也不增加购买容量。按约20个交易日估算，月容量约200元，不能填满300元基础目标，美国宽基袖套重新标记为容量不足。
- 096001为独立的大成标普500等权重路线，当前渠道日限10元、申购费0.15%。它覆盖标普500全部成份股但采用等权而非市值加权，因此只补充剩余容量，不替代017641的标准标普500主路线。按20个交易日估算，两组独立路线合计约400元，可覆盖300元基础目标。
- 519981当前渠道单笔最低1元、日限10元；爱基金只读费率接口核验100万元以下渠道申购费为0.14%。它被纳入第四优先级后备路线，但因标的是标普100等权重且允许不高于15%的主动增强，不能替代标准标普500基准，只在前三条路线无法填满袖套时补容量。011706是同一基金的美元份额，但当前渠道不支持交易，只保留一次性研究参考，不进入购买池或日常同步池。
- 英国宽基候选539003当前渠道日限5,000元，进入候选购买路由；006282虽日限500元，但属于主动欧洲策略，只作为主动参考，不与富时100路线合并容量。
- 美国成长袖套当前购买候选为000043，按当前渠道每日100元限额建模。
- 539001在重新核验当前渠道可购状态前不进入购买候选；如账户仍持有，则继续更新净值并参与风险分析。
- 权威配置为 `config/qdii_purchase_route_pool_v1.json`。

## 结果

购买可行性、研究可比性和持仓风险由三个集合分别表达。这样既不会给出无法执行的“纸上路线”，也不会为了可买而篡改长期基准，或遗漏已持有资产的风险。
