# ADR-0039：Web 交互式回测实验 V1

状态：采用。2026-10-11。

复用 local_research、申购事件引擎、组合估值和资金加权收益计算；Web 不实现第二套算法。为固定比例新增资金增加 fixed_weights 入口，复用现有直接分配函数。组合净值由引擎既有时间加权路径导出。

实验以 research_only / counterfactual_research_assumption 执行，官方规则门禁保持 blocked。用户配置冻结成 JSON 规格并绑定哈希和净值批次。只读已发布通过门禁的本地净值；不改变持仓、登记策略、政策或交易凭证。

V1 再平衡仅使用新增资金：固定比例或补低配，不卖出。每月 1–28 日投入，按基金下一可用净值日作为申购日、该日单位净值成交，下一条基金净值记录日作为保守可见/确认日；分配时只使用此前可见数据。NAV 日期只是研究交易日代理，不代表核验过的交易日历。单位净值、现金分红，不前向填充。显式设置研究申购费（比例前端扣费模型）、最低订单 1 元、无限额、份额两位向下取整；管理托管费用已反映于净值，不重复扣除。

实验保存到 data/private/web_backtests.sqlite3，不写基金或持仓数据库。保存只接受服务端已计算的 run_id 与名称，不信任客户端结果。新旧实验保留完整引擎输出和输入哈希；重跑读取当前已发布数据，旧结果不被覆盖。比较允许不同现金流，但不将差值当作策略优劣，横轴为实际日期。

每次运行通过 SQLite backup 获取临时本地一致性快照，避免晚间维护在回测过程中发布新批次造成混合版本；临时目录私有，计算后清除，保留的结果只有净值和研究证据。

市值独立四舍五入与总市值四舍五入的分差在最大仓位上调整，不作为可投资现金。容差限定为显示取整边界，超出边界仍失败关闭。份额向下取整的差额沿用原引擎计为舍入损耗，不虚构退款。

请求限制 1–8 只基金、最长十年、每月金额不超过百万，服务端锁限制同时一次运行。历史数据不足、非有限数、重复代码、比例不等于 100%、不存在的基金均拒绝。无实盘接口依赖。
