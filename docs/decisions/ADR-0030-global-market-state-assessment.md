# ADR-0030：全球市场状态评估边界

- 状态：有效
- 日期：2026-08-29

## 决策

新增独立的`market_regime`确定性计算层和`GlobalMarketStateSnapshot`契约。它只读取通过门禁的本地市场数据，按趋势、估值、宏观增长、流动性/利率、风险压力、市场宽度、拥挤/资金流七个轴汇总证据，并显式输出覆盖率、严格时点比例、来源数量、缺失能力和冲突。

现有`metrics.market_state`继续表示基于单只基金净值的`fund_regime_v1`，不得改名或覆盖。`market-context-research`负责解释和路由；`market-data-collect`负责采集和归档；`market_regime`负责本地确定性状态计算；`risk`可以消费合格快照，但保留独立否决权。

第一版快照固定为`research_only`。覆盖率低于60%时，即使已观察部分指标方向一致，也只能输出`insufficient_evidence`。满足状态覆盖不等于满足正式决策：正式资格还要求至少80%覆盖、全部使用严格点时证据、至少两个独立提供方以及后续风险层验收。

快照只允许`supportive/balanced/restrictive/insufficient_evidence`等描述性状态，不输出短期涨跌预测、收益目标、策略信号、目标权重、订单或真实交易动作。

## 数据源决策

- 股叉叉现有七个允许工具继续提供估值、宏观、利率、汇率、杠杆、权重和拥挤证据；不开放个股筛选、个股全景、DCF和私人自选；
- FinClaw仅作方法和接口线索参考，不采用其运行时自动fallback；
- 雪球未授权/cookie接口因官方条款和凭证风险拒绝；
- 新指数价格、宽度、波动和资金流来源必须逐数据族完成raw-first适配、许可/字段/时点审查、质量测试和第二来源计划，不能整包升权。

## 理由

- “当前市场如何”同时涉及多个地区和不同经济维度，不能由单只基金曲线或一条宏观指标代表；
- 先定义完整能力分母，缺数据就降低覆盖率，能防止系统只看自己碰巧拥有的数据；
- 把采集、状态、解释和风控分层，既可在新会话复用，也避免LLM把即时查询变成择时命令；
- 自动fallback适合交互查询，却会掩盖批次来源和语义切换，不符合可重放回测与风险证据要求。

## 后果

- 新增`config/global_market_regime_v1.json`、JSON Schema、`invest_agent.market_regime` CLI和自动化测试；
- 当前真实本地数据只能形成低置信度、不足覆盖的样例快照，这一结果是正确的失败关闭，不是系统故障；
- 后续优先补指数价格历史、A股日终宽度和官方波动/信用压力数据；
- 任何状态阈值、轴权重或来源替换都必须版本化配置并重新回放，不能在解释阶段临时修改。
