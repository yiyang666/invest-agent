# ADR-0020：Phase 6.2草案转换与持久化批准

- 日期：2026-08-25
- 状态：accepted
- 范围：mock only

## 决策

决策报告不能直接变成订单。只有同时满足以下条件的冻结模拟计划，才能转换为可展示的 `MockOrderDraft`：风险状态在允许范围、月度计划状态为 `mock_schedule_frozen`、不是月中预览、具有明确扣款日期、来源报告仍保持零订单和真实交易关闭。

转换时必须再次核验购买路由仍在版本化路由池中，并重新检查单路由及共享组日限额；路由规则标识从已核验的路由池、基金代码和生效时间确定性派生。基金、金额、日期、路由规则、费率、脱敏账户别名和来源证据哈希共同绑定进订单摘要。缺少费率、路由失效、超过限额或任一关键字段不完整时失败关闭。

批准状态保存到Git忽略的私有SQLite库。一次性消费使用数据库事务原子更新，因此进程重启后批准仍有效，并发消费者最多一个成功。数据库不保存完整账户号、支付凭证、token、设备标识或远端响应。

## 当前限制

当前2026-08-25决策包是月中诊断，风险状态为 `review_required_no_risk_increasing_action`，因此应被转换门拒绝，不能产生模拟订单。Phase 6.2的实现只证明合法计划未来可以安全进入mock审批，不改变当前投资结论。

## 验收

- 当前月中诊断包转换失败；
- 合法冻结计划生成的摘要包含全部关键字段和来源哈希；
- 路由或费用未知时失败；
- SQLite批准跨进程实例可消费；
- 两个并发消费者只有一个成功；
- 所有产物继续标记 `mock_only`、无网络、无真实交易。
