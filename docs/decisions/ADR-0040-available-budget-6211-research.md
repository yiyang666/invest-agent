# ADR-0040：核心渠道定投与0～2000可用预算的6211研究

- 日期：2026-10-12
- 状态：研究；政策迁移待用户裁决
- 范围：离线research_only；无Web新功能、无真实订单

用户月末充值5000，核心按日/周和估值高级定投，实际可能2600～3600。用户明确要求研究简化为：核心固定3000仅对照，交给Agent的可用资金0～2000。不模拟充值/结算周期，不把2600～3600预测为预算。实际操作只接受已经明确可用的预算。此前结算滞后草案v0.1未运行绩效即撤回。

新增薄的broker_core_residual分配器，核心预算外生、管理预算独立受限；继续复用本地门禁、申购/确认/分红/估值/XIRR/TWR。管理资金只补债、黄金与合格卫星的全组合目标缺口；不能自动补核心。红利从60%核心内划出。卫星缺额保持显式现金。预算小于2000且核心长期3000时，资金流会偏向核心，季度应提示调整渠道定投；不承诺新资金必然保持6211。

回测主方案与预算0/1000/2000分别匹配3000/4000/5000的631基准；不同预算终值不比较为策略超额。RSI13只检验新增资金准入；目前没有通用赎回引擎，不宣称已测试止盈。原631权威、政策、安全权限和注册表不自动迁移。高级回测不进入Web。
