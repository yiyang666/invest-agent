# ADR-0023：启用Phase 7逐笔受控申购

- 日期：2026-08-25
- 状态：accepted
- 范围：真实申购

## 决策

在用户明确授权真实接入、Phase 6收口、爱基金只读预检与CLI dry-run通过后，系统从 `advisory_only` 切换到 `controlled_live`，仅开放申购。赎回和撤单继续关闭，自动交易、自动重试和基金替换继续禁止。

每笔申购必须重新完成当轮产品与账户预检、支付方式选择、协议确认、精确订单摘要和15分钟一次性最终确认。订单提交后立即查询详情；网络、5xx、超时或响应异常时不重试，只进入状态对账。

长期绝对单笔、单日、单月上限均为5000元且不得超过当月剩余额度；首笔试运行额外限制为一笔、最多500元。撤单能力不作为申购安全保障。
