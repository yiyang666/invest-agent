# ADR-0041：本机 Web 登记同花顺核心定投计划

日期：2026-10-15；状态：采用（试运行登记功能）。

用户决定核心定投继续由同花顺执行，沪深300不再采用动态定投，希望在本机页面逐只登记定投频率、日期与每次金额。爱基金已审查 CLI 的交易列表能返回定投交易类型、金额、状态和确认日，不能读取同花顺当前定投计划的完整设定。因此计划来自用户人工登记，交易执行事实未来从只读交易归档获取，两者必须分开标示。

新增 `/api/core-dca`，只允许在已有回环地址、Host/Origin 守卫下读取和保存一份手动计划。保存目标是 `data/private/web_core_dca.sqlite3`，以追加修订保留历史；不写 `investment_policy.yaml`、策略注册表、主投资数据仓或真实账户。服务端严格校验基金代码、每日/每周/每月频率、日期、1～5000元金额和页面修订号。页面无交易接口、无自动同步同花顺计划的能力；保存只是本机登记，不能视为同花顺修改成功。

2026-10-15 补充：用户完成登记后需要防误改锁。新增持久锁定状态与 `/api/core-dca/lock`，锁定和解锁都要求最新修订号并追加修订；锁定时服务端拒绝保存计划，前端同时禁用编辑控件。锁只是本地计划的误操作保护，不是账户认证，也不会影响同花顺定投。未保存的页面草稿不能直接锁定，须先保存。

本阶段页面复用已有持仓快照显示计划基金的市值，但市值不是定投实绩。交易归档与完整性门禁尚未实现时，已买金额、待确认金额均显示“待接入”，不能从市值差或钱包余额推断。6211目标、红利归属、管理预算和卫星规则仍处于共同决策阶段，此登记不激活6211生产策略，也不解除逐笔交易确认与赎回关闭边界。
