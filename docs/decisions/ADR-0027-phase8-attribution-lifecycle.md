# ADR-0027：Phase 8归因与策略生命周期收口

- 日期：2026-08-27
- 状态：accepted
- 范围：组合归因、策略比较与生命周期

## 决策

Phase 8工程收口。归因采用四层契约：现金流层区分本金、投资损益、费用和现金拖累；组合层使用Modified Dietz并几何链接；袖套层使用Brinson-Fachler配置、选择和交互效应；策略层使用运行前冻结的顺序消融瀑布。

候选策略只有在估值期间和外部现金流与631基准完全匹配时，才能报告相对策略结果。资产池、长期权重或政策骨架改变产生的是“总政策结果”，不能包装成择时或信号alpha。现金始终保留为显式袖套。

策略生命周期由版本化阈值和证据哈希约束。少于12个完整前瞻月只能继续观察；风险否决、陈旧数据、现金流比较器缺失或确定性复跑失败均阻断评价；达到预设阈值只会进入人工晋级或退役评审。系统不自动晋级、退役、生成订单或提交交易。

工程能力完成不等于已经积累足够真实历史。真实账户归因从可核验快照和现金流开始按月累积，历史回填不得冒充前瞻证据。
