## 不可妥协的结果

1. 账户和支付凭证不进入仓库、日志或报告。
2. 远端数据必须先归档、校验并写入本地仓；失败不回落到模拟值。
3. 正式回测需要真实产品/渠道规则；显式假设只能标记为研究。
4. 策略和风险由确定性代码计算，LLM没有金额或风控最终权力。
5. 自动真实交易默认关闭；当前唯一例外是逐笔精确批准的受控申购，任何关键字段变化都会使用户批准失效。

以后出现新的重大、安全或不可逆架构决定时，可新增独立ADR；普通实验结果进入机器可读产物或私有报告，不再为每个步骤创建文档。
