# ADR-0024：研究级赎回引擎与两阶段比较

- 日期：2026-08-26
- 状态：proposed
- 范围：research_only backtest
- 实盘影响：无；真实赎回继续关闭

## 背景

当前 `dca_baseline@1.5.0` 和通用研究引擎均为买入型：外部新增资金按目标缺口申购，允许现金、在途申购和限额队列，但不卖出已有份额。`hierarchical_risk_budget_valuation@0.2.0` 也冻结为 `new_money_only`。

完整三层构想包含卫星红灯减仓和季度再平衡。如果在现有申购引擎中直接减份额、立即增加现金，会同时错过持有批次、赎回费、开放日、确认、到账和巨额赎回语义，并夸大可再投资资金。

## 决策

采用两阶段研究，不把两种策略混成同一版本：

1. 先实现并回测 v0.2.0 买入版，作为分层信号的消融基线；
2. 另建 v0.3.0 赎回扩展，在任何绩效运行前冻结卖出规则；
3. v0.3.0 首版只测试“卫星连续红灯后的分段风险退出”，不同时引入核心估值卖出、防御卖出和全组合季度轮动；
4. 只有 v0.3.0 相对 v0.2.0 在费用后稳定改善尾部风险，才研究更完整的季度买卖版本。

研究级赎回引擎属于公共回测基础设施，不放在单一策略函数里。它必须维护以下互斥状态：

- 可用现金；
- 在途申购现金；
- 可用份额及持有批次；
- 已提交、尚未确认的在途赎回份额；
- 已确认、尚未到账的赎回款；
- 已到账、来源为赎回的内部现金。

赎回申请提交后先冻结相应份额，不产生可用现金。确认后按每批持有期和有效日期费率计算净赎回款；款项到账后才成为内部现金。到账资金在本次月度决策周期内不再投入，最早于下一个固定月度决策使用。

赎回款不是外部现金流，不计入当月3,000元稳定投入或0–2,000元机动预算，也不为 matched-cashflow 631 增加本金。下个月它作为已有组合现金参与动态目标缺口计算；没有合格缺口时继续留存现金。

## 层级职责

- 高层只产生风险预算或停止增加风险的目标，不直接构造赎回单；
- 底层只产生袖套状态与目标，不直接改份额或现金；
- 中层是唯一净额合并器：先纳入现金、在途、当月新增资金计划和动态目标，再判断是否存在合格卖出差额；
- 独立风险层可以否决或要求人工复核，但不能被策略改写；
- 研究引擎只模拟事件，不能调用真实交易接口。

## 公平比较

正式报告至少并列四条路径：

1. 固定每月3,000元的权威631 v1.5；
2. 与候选逐月外部现金流完全相同的买入型631 v1.5；
3. 候选 v0.2.0 买入版；
4. 候选 v0.3.0 赎回版。

v0.3.0 对 v0.2.0 是赎回机制的主要增量检验；v0.3.0 对631是完整政策结果比较，但必须明确两者交易权限不同。后续可增加一个使用相同赎回引擎、相同调整频率和费用语义的简单631带宽再平衡研究对照，但它不替代权威 `dca_baseline@1.5.0`。

## 后果与门禁

- v0.2.0 的结果不能代表完整卖出策略，v0.3.0 的结果也不能回填改名为 v0.2.0；
- 探索版赎回可使用明确版本化的当前渠道只读快照、FIFO和两位四舍五入等反事实规则，但必须标记 `counterfactual_execution` 并做费用/到账敏感性；晋级前仍须补齐与卖出动作相关的批次消耗顺序、持有日计算、有效日期费率、最低份额、截止时间、开放日、确认与到账规则；
- 必须覆盖分批申购后赎回、短期费率、QDII日历、份额精度、巨额赎回延期、在途资金和现金守恒测试；
- 实盘赎回仍受 `ADR-0023` 禁止。本ADR不改变投资政策、执行权限或人工逐笔确认要求。
