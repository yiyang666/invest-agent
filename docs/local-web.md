# 本机投资工作台

macOS 可双击仓库根目录的 `启动投资看板.command`，它会启动服务并打开浏览器。保持弹出的终端窗口运行即可。

也可在仓库根目录运行：

```sh
scripts/run_local_web.sh
```

打开 http://127.0.0.1:8765 。终端保持运行，Ctrl+C 停止；端口冲突可加 `--port 8766`。使用项目现有 `.conda-env`，无新增依赖。Web 只监听本机，不能从其他设备直接访问。

### Ubuntu 通过 SSH 使用 Mac mini 上的工作台

项目运行在 Mac mini 时，Mac 的 `127.0.0.1:8765` 与 Ubuntu 浏览器的 `localhost` 不是同一台机器。先在 Mac mini 上启动 `scripts/run_local_web.sh` 并保持服务运行；随后在 Ubuntu 终端使用与 Codex 远程连接相同的 SSH 主机别名建立本地转发：

```sh
ssh -N -L 18765:127.0.0.1:8765 <Mac-mini-SSH主机别名>
```

保持这个终端运行，在 Ubuntu 浏览器打开 `http://127.0.0.1:18765/#core_dca`。若使用 Codex 自动生成的 `localhost:<随机端口>` 页面，先确认 Mac 端服务仍在运行，再刷新页面；随机端口不能代替稳定的 SSH 转发配置。不要把 Web 服务改成监听 `0.0.0.0`，因为页面包含个人持仓与本地投资计划。

页面包括投资总览（最新基金收益、持仓分布与宏观市场）、监控基金（搜索、双分类、净值与采集质量、可切换区间的业绩走势，以及独立的13期RSI净值波动图）、每日持仓（日期选择、金额隐藏）、策略库（登记与历史版本、规则详情、明确绑定的本地回测摘要）、数据更新（维护作业状态与运行记录）。业绩走势支持近1月、3月、6月、1年、3年和全部，并按显示区间首尾累计净值计算收益率；选择近3年但历史不足时自动展示全部历史并给出短暂提示。RSI对最近13个累计净值变化采用简单上涨/下跌幅度汇总，已用多只基金的同花顺同日值核对；页面区间按钮只裁剪展示。30/70色带表达近期涨跌力量，不等同于跟踪指数PE TTM五年估值分位，也不直接生成交易建议。

## 6211 试运行：核心定投登记

从侧栏进入“6211 试运行”（`#core_dca`），添加同花顺中实际设置的每只核心基金计划，填写每日、每周或每月、星期/日期及每次金额。标普500等多基金路线可逐条登记；更改或移除后点击“保存本地登记”，修改以追加修订保存到私有 `data/private/web_core_dca.sqlite3`。页面同时展示这些基金在最新持仓快照中的市值和快照时间。

编辑完成后点击“🔒 锁定计划”防止误改；锁定状态会保存在本地，刷新页面仍有效。锁定时输入框停用，服务端也拒绝保存；后续需要修改时点击“🔓 解锁编辑”。有未保存的修改时先保存再锁定。锁只保护本地登记，不会暂停或改变同花顺的定投。最新快照没有某只基金时显示“快照未持有”，不能据此判断是否已有待确认申购。

登记是同花顺计划的**人工副本**，保存不会在同花顺创建、修改或取消定投。当前爱基金 CLI 能查询定投交易记录，但不能读取计划的完整频率/额度；网页尚未归档交易流水，所以“已买金额”和“待确认金额”明确显示待接入。持仓市值受净值涨跌影响，不能当作本月定投金额。若同花顺遇节假日顺延，实际发生日以后续交易记录为准。此页面不会启用6211实盘策略或提交订单。

同页的“卫星仓 · 行业观察池”读取 `config/satellite_industry_watchlist_v1.json` 和已发布、质量通过的本地市场数据。首批10个行业之外，应用户要求加入农林牧渔，现共11个。页面展示行业、领域、最近综合拥挤度及观察日期；超过 7 天会标记“旧数据”。行业池只是跨领域观察范围，未按收益或拥挤度筛选，也没有买入信号。周频市场维护负责后续刷新，不在打开网页时调用外部接口。

其上方的“重点研究方向”记录 AI 硬件、机器人、太空算力、物理 AI 和厄尔尼诺相关农业的主题偏好，并把已监控基金明确标为局部研究代理。这些标签不是独立仓位；物理 AI 与机器人重叠，卫星/商业航天基金也不等同于纯太空算力基金。厄尔尼诺的农业影响因地区、作物和季节而异，农林牧渔行业并非气候事件的直接收益代理。页面不依据主题名称、新闻或行业拥挤度生成申购建议。

“场外基金研究路线”另列产品与证据进度。016077 已有通过本地质量门禁的近三年基金净值与一次爱基金只读规则核验，但它只代表农业产业，不代表厄尔尼诺收益；028777 仅核对了产品身份，成立时间很短，只能前瞻观察。007300、014880 沿用既有研究代理。表中的基金均不是已批准的 6211 买入池；具体研究证据与缺口见 `strategies/proposals/6211_trial_v0_1_discussion.md`。

“接口配置”是首次部署入口。页面先展示同花顺爱基金 Skill 的官方说明、App 授权步骤和可复制给 Agent 的安全安装提示词；用户也可只粘贴 App 生成的一次性 `initToken`，由受审查的项目级 `aijijin auth init` 完成设备注册。`initToken` 不保存，Work Token / Refresh Token 不由网页读取或展示；长期凭证仍由 CLI 写入权限为 `0600` 的 `~/.aijijin/credentials.json`，App 最终授权需由用户自己确认。

股叉叉和金十 MCP 令牌从浏览器直接提交给当前本机服务，通过 macOS `security` 的标准输入写入登录钥匙串，不出现在进程参数中。两个官方入口均可从卡片标题直接打开。页面只显示“已配置/未配置/需要解锁或授权”，不会回显明文；解锁教程集中在状态后的感叹号弹窗中，不在两张卡片重复显示。保存后输入框立即清空。页面关闭后配置仍然有效，日常维护、定时任务和数据 CLI 继续沿用原有的“进程环境变量优先、缺失时读取钥匙串”流程，不依赖网页运行。无论网页在本机直接打开还是通过 SSH 端口转发访问，这一存储路径都相同。

宏观市场位于总览开头，使用紧凑的红涨绿跌渐变卡片。上证指数和科创综指来自上交所日终公开页面，创业板指来自国证指数官网日线，纳斯达克综合指数与纳斯达克100来自 FRED 的指数收盘序列；沪深300、恒生、标普500、富时100、德国DAX和日经225沿用金十精选报价。每项均先原始归档、校验并发布到本地市场数据表，网页只读数据库；卡片单独标注观察日期和来源，不把基金净值代理标成指数点位。不同来源可能延迟不同，假日也不会填造新值。上交所、国证指数和 FRED 来源限个人本地研究，不对外转载指数行情。

晚间统一 `market_daily_series` 作业采集这些来源。点击“更新金十报价”只运行既有金十精选报价采集，不查询账户、不运行策略，也不生成订单；其他指数由晚间市场作业更新。采集失败时保留上一次通过门禁的本地值。股叉叉与雪球链接仅供人工打开，网页不会自动抓取。股叉叉估值接口虽然包含部分指数点位，但其 `change_pct` 不是日涨跌幅，时间字段也与行情交易日不符，因此不用于指数卡片。

手工更新需要启动 Web 的进程环境包含 `JIN10_MCP_TOKEN`，或在“接口配置”中保存金十令牌。登录钥匙串锁定或当前会话不允许钥匙串交互时，页面会展示本机和 SSH 场景下的解锁步骤。可以在部署项目的 Mac 上打开“钥匙串访问”并解锁“登录”钥匙串，或在交互式终端运行 `security unlock-keychain ~/Library/Keychains/login.keychain-db` 后按提示输入系统登录密码；密码不得写进命令或网页。缺少凭证时继续使用上次数据，不会降级写入明文文件。

页面首次打开时读取一次完整本地视图；此后每 10 分钟只检查 SQLite、配置、策略、回测和维护记录的轻量版本，版本未变化时不查询或重建完整视图。页面从后台恢复可见时也遵循同一检查间隔。版本变化后自动加载新数据；基金净值详情按数据版本缓存在浏览器内。右上角“刷新”会立即重建本地视图，但不触发账户查询或远程采集。

## 策略回测 V1.0

从侧栏进入“策略回测”（`#backtests`）。搜索已发布、通过质量门禁的本地基金，逐只添加，输入目标比例和研究申购费率；比例必须精确合计 100%。最多 10 只基金、最长十年。添加基金时日期自动收敛到共同可用历史，运行前可再调整。历史窗口外的参数会直接报错，不静默截短。

输入每月金额、回测起止日期与每月 1–28 日的定投日，选择“新增资金优先补低配”或“新增资金按固定比例”，点击“执行回测”。两者均只买不卖；补低配允许部署已有可用现金，固定比例只分配本月新增资金。页面复用既有 `local_research`、申购事件、估值与指标引擎，不新增回测算法。

结果包括累计本金、期末资产、累计收益、简单收益率、XIRR、时间加权收益、最大回撤、资产总值、组合净值及期末基金/现金占比。不同现金流的资产与 XIRR 不宜直接解读为配置优劣；组合净值扣除外部投入影响，从首个完整估值日归一化。首日前费用仍影响累计收益和 XIRR。无可计算 XIRR 时显示“—”。

**研究日期规则**：月度自然日确定预算，下单顺延到各基金下一条可用净值记录日，按该日单位净值成交，下一条基金净值记录日作为可见/确认日。分配只使用此前可见数据，不使用未来收益；净值日期是交易日代理，并非已经核验的渠道日历。估值不前向填充，缺少完整估值的日期跳过；页面披露实际期间、缺失次数与拒绝订单，最后完整估值必须覆盖最后一次投入。

**费用和现金**：用户输入显式研究费率，默认 0% 为零费假设。比例前端扣费：净申购金额 = 总金额 / (1 + 费率)，费用 = 总金额 − 净申购金额。管理和托管费用已在净值内。研究假设最低 1 元、无限额、两位份额向下取整；份额取整差额沿用引擎计为舍入损耗，不当作渠道退款。未路由金额留现金，不计息；现金分红下一净值日到账。期末资产包含可用现金、在途申购和分红应收。官方历史交易规则门禁始终 blocked。

分红只使用本地已发布的分红记录；缺失的分红或拆分信息会影响结果，不以累计净值补造交易事件。需要正式策略证据时仍走原有数据完整性与策略晋级门禁。

运行后填写实验名称并点击“保存实验”。名称 1–80 字，配置、完整结果、规则和批次哈希保存到私有 `data/private/web_backtests.sqlite3`，不会写入基金/持仓仓库或策略注册表。服务临时保留最近 16 个未保存结果；服务重启后未保存结果需重新运行。加载历史保留原计算结果；修改配置后执行回测生成新的实验，不覆盖旧结果。已保存实验可更名保存，也可在历史列表确认后永久删除；删除只影响所选实验，并同步移出当前结果和对比区。

点击“加入对比”，最多同时比较 6 组指标和净值曲线，横轴使用实际日期。配置不同时页面提醒核对金额、期间和定投日期，不自动挑选“最优策略”。

本地接口：`GET /api/backtests/catalog`、`GET /api/backtests`、`GET /api/backtests?id=…`、`POST /api/backtests/run`（配置）、`POST /api/backtests/save`（服务端 run_id、名称）、`DELETE /api/backtests?id=…`。沿用同源、localhost 防护和请求大小限制，同一时间仅允许一次计算、保存或删除。

基础验证：`.conda-env/bin/python -m unittest tests.test_web_backtests tests.test_local_research_backtest tests.test_local_web`。覆盖恒定净值、手续费、现金守恒、低配分配、日期与可见时间、非法参数、不可伪造结果、保存恢复及 HTTP 边界。完整测试使用 `.conda-env/bin/python -m unittest discover -s tests`。

## 数据来源

- 净值、持仓与已发布市场报价：`data/private/invest_agent.sqlite3`。所有视图查询均为只读；只有“更新金十报价”可以通过固定脚本追加一批允许列表内的金十报价。
- 分类与监控集合：`config/fund_watch_catalog_v1.json` 提供稳定的监控分类，研究池、购买路由池和已登记月度持仓分类可提供更具体的既有分类；未登记的基金显示“待分类”。
- 策略：`strategies/registry.json` 与 `strategies/specs/`，检验登记证据，不把研究状态当成实盘执行。
- 更新记录：统一维护任务私有状态与报告。
- 核心定投设置：用户在网页手工登记的同花顺计划副本；不与同花顺计划双向同步。

持仓展示采集时刻的渠道快照。渠道给出净值日期、收益日期时分别展示，否则显示“未提供”，不会自动标成上一交易日。钱包或基金分类采集不完整时提示部分数据。除用户点击“更新金十报价”外，浏览页面不调用外部数据源或模型；网页没有交易接口。

总览基金收益只汇总最新渠道快照中各持仓的 `latest_income`，钱包资产始终排除。渠道没有提供统一收益日期时如实提示，并单独列出快照采集时间；不根据资产差额自行推算。

## 日常维护

晚间总控在同一固定会话分两次触发：22:35 运行 22:30 到期的 `portfolio_daily` 只读持仓快照，23:35 再运行 23:30 到期的基金净值和市场数据。两次仍共用统一CLI、状态、锁和运行记录。手工运行也应使用统一入口：

```sh
scripts/run_data_maintenance_cli.sh plan
scripts/run_data_maintenance_cli.sh run-job --job-id portfolio_daily
```

旧的脱敏持仓 JSON 可一次性导入（失败门禁记录自动拒绝）：

```sh
.conda-env/bin/python -c 'from pathlib import Path; from invest_agent.data.portfolio_store import import_snapshots; print(import_snapshots(Path("data/private/invest_agent.sqlite3"),Path("data/private/portfolio_snapshots")))'
```

Web 不负责调度唤醒；晚间任务仍依赖现有 Codex 自动化运行环境和 CLI 登录状态。登录失效或采集失败会保留历史快照并显示更新作业失败。测试用例只使用临时合成数据，不把个人持仓提交到 Git。
